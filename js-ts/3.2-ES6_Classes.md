# 3.2 ES6 Classes

ES6 (ECMAScript 2015) introduced the `class` keyword, which provides a much cleaner and more familiar syntax for creating objects and handling inheritance.

**Important**: JavaScript classes are **syntactic sugar** over JavaScript's existing prototypal inheritance model. They do not introduce a new object-oriented inheritance model to JavaScript. They simply provide a simpler way to work with prototypes.

## Basic Class Syntax

A class is a blueprint for creating objects.

```javascript
class Animal {
  // The constructor is a special method for creating and initializing an object
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  // Methods are defined directly inside the class
  speak() {
    console.log(`${this.name} makes a sound.`);
  }
}

// Create a new instance of the class
const animal1 = new Animal("Leo", 5);
animal1.speak(); // "Leo makes a sound."

console.log(animal1.name); // "Leo"
```
Under the hood, the `speak` method is added to `Animal.prototype`.

## Inheritance with `extends` and `super`

The `extends` keyword is used to create a child class that inherits from a parent class.

The `super` keyword is used to call the constructor of the parent class and to access the parent's methods.

```javascript
// Parent Class
class Animal {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  speak() {
    console.log(`${this.name} makes a sound.`);
  }
}

// Child Class
class Dog extends Animal {
  constructor(name, age, breed) {
    // Call the parent constructor with super()
    // This MUST be done before using `this` in a child constructor
    super(name, age);
    
    this.breed = breed;
  }

  // Override the parent's speak method
  speak() {
    console.log(`${this.name} barks.`);
  }

  // Call the parent's method using super
  parentSpeak() {
    super.speak();
  }
}

const myDog = new Dog("Buddy", 3, "Golden Retriever");

myDog.speak(); // "Buddy barks." (The overridden method is called)
myDog.parentSpeak(); // "Buddy makes a sound." (The parent method is called)
console.log(myDog.age); // 3 (Property inherited from Animal)
```

## Getters and Setters

Classes allow you to define getters and setters to control access to an object's properties.

```javascript
class User {
  constructor(firstName, lastName) {
    this.firstName = firstName;
    this.lastName = lastName;
  }

  // Getter
  get fullName() {
    return `${this.firstName} ${this.lastName}`;
  }

  // Setter
  set fullName(newName) {
    const [firstName, lastName] = newName.split(' ');
    this.firstName = firstName;
    this.lastName = lastName;
  }
}

const user = new User("John", "Doe");
console.log(user.fullName); // "John Doe" (Called like a property, not a method)

user.fullName = "Jane Smith"; // Use the setter
console.log(user.firstName); // "Jane"
console.log(user.fullName);  // "Jane Smith"
```

## Static Methods

Static methods are defined on the class itself, not on the instances of the class. They are often used for utility functions that relate to the class. You call them directly from the class name.

```javascript
class MathHelper {
  static PI = 3.14159;

  static add(a, b) {
    return a + b;
  }
}

console.log(MathHelper.PI); // 3.14159
console.log(MathHelper.add(5, 10)); // 15

const mathInstance = new MathHelper();
// console.log(mathInstance.add(2, 3)); // TypeError: mathInstance.add is not a function
```

## Private Fields (Recent Addition)
A more recent addition to JavaScript allows for truly private class fields by prefixing them with a `#`. These fields cannot be accessed from outside the class.

```javascript
class BankAccount {
  // This is a private field
  #balance = 0;

  constructor(initialBalance) {
    this.#balance = initialBalance;
  }

  deposit(amount) {
    if (amount > 0) {
      this.#balance += amount;
    }
  }

  getBalance() {
    return this.#balance;
  }
}

const account = new BankAccount(100);
account.deposit(50);
console.log(account.getBalance()); // 150
// console.log(account.#balance); // SyntaxError: Private field '#balance' must be declared in an enclosing class
```
