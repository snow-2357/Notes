# 4.4 Functions and Classes in TypeScript

TypeScript enhances JavaScript's functions and classes with a robust type system, making them more predictable and easier to work with.

## Functions in TypeScript

### Typing Parameters and Return Values
You can (and should) add type annotations to a function's parameters and its return value.

```typescript
// This function takes two numbers and is expected to return a number.
function add(a: number, b: number): number {
  return a + b;
}

// The return type can often be inferred, but explicit is clearer.
function greet(name: string): void { // `void` means this function doesn't return a value
  console.log(`Hello, ${name}`);
}
```

### Optional and Default Parameters
-   An **optional parameter** is marked with a `?`. It can be `undefined`.
-   A **default parameter** is assigned a value in the function signature if none is provided.

```typescript
// `lastName` is optional
function createFullName(firstName: string, lastName?: string): string {
  return lastName ? `${firstName} ${lastName}` : firstName;
}

console.log(createFullName("John")); // "John"
console.log(createFullName("John", "Doe")); // "John Doe"

// `greeting` has a default value
function sayGreeting(name: string, greeting: string = "Hello"): void {
  console.log(`${greeting}, ${name}!`);
}

sayGreeting("World"); // "Hello, World!"
sayGreeting("World", "Hi"); // "Hi, World!"
```

### Function Overloads
Function overloading allows you to define multiple function signatures for a single function body. This is useful when a function can be called in different ways.

The implementation signature (the one with the code) must be compatible with all the overload signatures.

```typescript
// Overload signatures
function makeDate(timestamp: number): Date;
function makeDate(year: number, month: number, day: number): Date;

// Implementation signature
function makeDate(mOrY: number, month?: number, day?: number): Date {
  if (month !== undefined && day !== undefined) {
    // This is the second overload (y, m, d)
    return new Date(mOrY, month, day);
  } else {
    // This is the first overload (timestamp)
    return new Date(mOrY);
  }
}

const d1 = makeDate(12345678);
const d2 = makeDate(2025, 11, 24);
// const d3 = makeDate(2025, 11); // Error: No overload matches this call.
```

## Classes in TypeScript
TypeScript builds upon ES6 classes, adding features like access modifiers and explicit property declarations.

### Property Declaration
In TypeScript, you should declare class properties at the top of the class.

```typescript
class Person {
  // Property declarations
  name: string;
  age: number;

  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }

  introduce(): void {
    console.log(`Hi, I'm ${this.name} and I'm ${this.age} years old.`);
  }
}
```

### Access Modifiers
Access modifiers control the visibility of class members (properties and methods).

-   **`public`** (default): The member can be accessed from anywhere.
-   **`private`**: The member can only be accessed from within the class itself.
-   **`protected`**: The member can be accessed from within the class and any subclasses that extend it.

```typescript
class BankAccount {
  public readonly owner: string;
  private _balance: number; // Convention to prefix private props with `_`

  constructor(owner: string, initialBalance: number) {
    this.owner = owner;
    this._balance = initialBalance;
  }

  public deposit(amount: number): void {
    if (amount <= 0) {
      this.logError("Deposit amount must be positive.");
      return;
    }
    this._balance += amount;
  }

  public getBalance(): number {
    return this._balance;
  }

  private logError(message: string): void {
    console.error(`Error for account ${this.owner}: ${message}`);
  }
}

const myAccount = new BankAccount("Alice", 100);
myAccount.deposit(50);
console.log(myAccount.getBalance()); // 150
// console.log(myAccount._balance); // Error: Property '_balance' is private
// myAccount.logError("test"); // Error: Property 'logError' is private
```

### Parameter Properties (Shorthand)
As a shortcut, you can declare and initialize class members directly in the constructor by using access modifiers on the parameters.

This code:
```typescript
class Product {
  public name: string;
  private price: number;

  constructor(name: string, price: number) {
    this.name = name;
    this.price = price;
  }
}
```
Is equivalent to this shorthand:
```typescript
class Product {
  constructor(public name: string, private price: number) {
    // No need for `this.name = name` etc.
    // TypeScript generates the properties and assignments for you.
  }
}
```
