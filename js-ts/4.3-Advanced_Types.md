# 4.3 TypeScript: Advanced Types

Beyond the basics, TypeScript provides powerful features for creating flexible and robust types.

## Union Types (`|`)
A union type allows a variable to be one of several types. The pipe character `|` acts as an "OR".

```typescript
// `id` can be either a number or a string
function printId(id: number | string) {
  // We need to narrow the type before using methods specific to one type
  if (typeof id === "string") {
    console.log(id.toUpperCase());
  } else {
    console.log(id);
  }
}

printId(101);       // 101
printId("202");     // 202
// printId({ id: 3 }); // Error
```

## Intersection Types (`&`)
An intersection type combines multiple types into one. The new type has all the properties of all the types it intersects. It's used for creating a new type that is a **combination** of existing types.

```typescript
interface Draggable {
  drag: () => void;
}

interface Resizable {
  resize: () => void;
}

// A `UIWidget` must have BOTH a `drag` method AND a `resize` method.
type UIWidget = Draggable & Resizable;

let textBox: UIWidget = {
  drag: () => console.log("Dragging..."),
  resize: () => console.log("Resizing...")
};
```

## Generics (`<T>`)
Generics are one of TypeScript's most powerful features. They allow you to write reusable code that can work over a variety of types rather than a single one. We use a **type variable** (a placeholder, commonly `<T>`) that the user can specify.

### Generic Functions
Consider a function that returns the first element of an array.

```typescript
// Without generics, we might use `any`, which is not type-safe.
function getFirstElementAny(arr: any[]): any {
  return arr[0];
}

// With generics, we capture the type of the array element.
function getFirstElement<T>(arr: T[]): T | undefined {
  return arr[0];
}

const numbers = [1, 2, 3];
const firstNum = getFirstElement(numbers); // `firstNum` is inferred as type `number`

const strings = ["a", "b", "c"];
const firstStr = getFirstElement(strings); // `firstStr` is inferred as type `string`
```
`T` is the type variable. When we call `getFirstElement(numbers)`, `T` becomes `number`. The function signature becomes `(arr: number[]): number`, ensuring type safety.

### Generic Interfaces
You can also create generic interfaces.

```typescript
interface ApiResponse<T> {
  data: T;
  status: number;
  error: string | null;
}

// `userResponse` is an ApiResponse where `data` is a User object.
const userResponse: ApiResponse<{ name: string; id: number }> = {
  data: { name: "Gemini", id: 1 },
  status: 200,
  error: null,
};

// `productsResponse` is an ApiResponse where `data` is an array of strings.
const productsResponse: ApiResponse<string[]> = {
  data: ["Laptop", "Mouse"],
  status: 200,
  error: null,
};
```

## Utility Types
TypeScript comes with a set of built-in utility types that help you transform existing types.

### `Partial<T>`
Constructs a type with all properties of `T` set to optional. This is useful for writing update functions.

```typescript
interface User {
  name: string;
  email: string;
}

// `update` can contain one, all, or none of the User properties.
function updateUser(update: Partial<User>) {
  // ...
}

updateUser({ name: "New Name" }); // This is valid
```

### `Readonly<T>`
Constructs a type with all properties of `T` set to `readonly`.

```typescript
interface Point {
  x: number;
  y: number;
}

const p1: Readonly<Point> = { x: 10, y: 20 };
// p1.x = 5; // Error: Cannot assign to 'x' because it is a read-only property.
```

### `Pick<T, K>`
Constructs a type by picking a set of properties `K` from type `T`.

```typescript
interface Todo {
  title: string;
  description: string;
  completed: boolean;
}

// `TodoPreview` only has `title` and `completed` properties.
type TodoPreview = Pick<Todo, "title" | "completed">;

const todo: TodoPreview = {
  title: "Clean room",
  completed: false,
};
```

### `Omit<T, K>`
Constructs a type by picking all properties from `T` and then removing `K`. It's the opposite of `Pick`.

```typescript
interface Todo {
  title: string;
  description: string;
  completed: boolean;
  createdAt: number;
}

// `TodoInfo` has all properties from `Todo` EXCEPT `completed` and `createdAt`.
type TodoInfo = Omit<Todo, "completed" | "createdAt">;

const todoInfo: TodoInfo = {
  title: "Learn TypeScript",
  description: "Study advanced types",
};
```
