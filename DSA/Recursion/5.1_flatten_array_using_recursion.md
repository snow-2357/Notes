# Flatten Array using Recursion

## Problem

Write a recursive function to flatten a deeply nested array into a single-level array.

## Solution

We'll create a function that iterates through the array. If an element is an array itself, we'll recursively call the function on that element. Otherwise, we'll push the element into our flattened array.

```javascript
function flattenArray(arr) {
  const flattened = [];

  function flatten(element) {
    if (Array.isArray(element)) {
      for (const item of element) {
        flatten(item);
      }
    } else {
      flattened.push(element);
    }
  }

  flatten(arr);
  return flattened;
}

// Example
const nestedArray = [1, [2, [3, [4, 5]], 6], 7];
const flattenedArray = flattenArray(nestedArray);
console.log(flattenedArray); // [1, 2, 3, 4, 5, 6, 7]
```

This is a classic use case for recursion to handle nested data structures.
