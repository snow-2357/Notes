# 2.2 `useState` Hook

The `useState` Hook is the most fundamental Hook, allowing you to add state to functional components. It's the functional component equivalent of `this.state` and `this.setState()` in class components.

## Basic Usage:
To use `useState`, you import it from React and call it inside your functional component. It takes one argument: the initial state. It returns an array with two elements:

1.  **The current state value.**
2.  **A function to update the state.**

```jsx
import React, { useState } from 'react';

function Counter() {
  // Declare a state variable called "count"
  // and a function "setCount" to update it.
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
}
```

## Initial State:
The `useState()` argument is the initial state. It can be a primitive value (number, string, boolean) or an object/array.
If the initial state is computationally expensive to create, you can pass a function to `useState`. This function will only be executed once on the initial render.

```jsx
const [complexData, setComplexData] = useState(() => {
  // Perform some expensive computation to get initial state
  const initialState = someExpensiveFunction();
  return initialState;
});
```

## Updating State:
The state updater function (`setCount` in the example) does not automatically merge update objects like `this.setState` does in class components. When updating an object or array, you usually need to spread the previous state.

```jsx
const [user, setUser] = useState({ name: 'Alice', age: 30 });

// To update only the name:
setUser(prevUser => ({ ...prevUser, name: 'Bob' }));
```

If the new state depends on the previous state, it's recommended to pass a function to the state updater. This function will receive the previous state as an argument.

```jsx
function Counter() {
  const [count, setCount] = useState(0);

  const increment = () => {
    // Correct way to update state based on previous state
    setCount(prevCount => prevCount + 1);
  };

  return (
    <button onClick={increment}>
      Increment
    </button>
  );
}
```
This functional update form is important because React might batch state updates, and directly using `count + 1` could lead to using a stale `count` value if multiple updates happen rapidly.

## Multiple State Variables:
You can use `useState` multiple times in a single component to manage separate pieces of state.

```jsx
function ExampleWithManyStates() {
  const [age, setAge] = useState(42);
  const [fruit, setFruit] = useState('banana');
  const [todos, setTodos] = useState([{ text: 'Learn Hooks' }]);

  return (
    <div>
      <p>My age is {age}</p>
      <p>I like {fruit}</p>
      <ul>
        {todos.map(todo => <li key={todo.text}>{todo.text}</li>)}
      </ul>
      <button onClick={() => setAge(age + 1)}>Update Age</button>
      {/* ... other update buttons */}
    </div>
  );
}
```
