# 2.5 `useReducer` Hook

The `useReducer` Hook is an alternative to `useState` for managing more complex state logic in functional components. It is often preferred when state logic involves multiple sub-values or when the next state depends on the previous one. It's conceptually similar to Redux, providing a predictable state container.

## When to use `useReducer` vs `useState`:
*   **`useState`**: Ideal for simple state updates, where the logic is straightforward (e.g., toggling a boolean, incrementing a number).
*   **`useReducer`**: Better suited for complex state logic involving multiple actions, transitions between different states, or when the next state depends on the previous state. It's also great for managing global state in conjunction with `useContext`.

## Basic Usage:
`useReducer` takes two arguments:
1.  **`reducer` function:** This function receives the current state and an action, and returns the new state. `(state, action) => newState`.
2.  **`initialState`:** The initial state value.

It returns an array containing:
1.  **The current state.**
2.  **A `dispatch` function:** Used to dispatch actions to the reducer, which then updates the state.

```jsx
import React, { useReducer } from 'react';

// 1. Define the Reducer Function
const initialState = { count: 0 };

function reducer(state, action) {
  switch (action.type) {
    case 'increment':
      return { count: state.count + 1 };
    case 'decrement':
      return { count: state.count - 1 };
    case 'reset':
      return initialState;
    default:
      throw new Error();
  }
}

function Counter() {
  // 2. Use useReducer in your component
  const [state, dispatch] = useReducer(reducer, initialState);

  return (
    <div>
      <p>Count: {state.count}</p>
      <button onClick={() => dispatch({ type: 'increment' })}>Increment</button>
      <button onClick={() => dispatch({ type: 'decrement' })}>Decrement</button>
      <button onClick={() => dispatch({ type: 'reset' })}>Reset</button>
    </div>
  );
}
```

## Anatomy of `useReducer`:

*   **`reducer(state, action)`:**
    *   `state`: The current state of your component.
    *   `action`: An object that describes what happened (e.g., `{ type: 'increment' }`). By convention, actions are objects with a `type` property, and can have other properties (payload) to carry additional data.
    *   This function must be a pure function: given the same `state` and `action`, it should always return the same new `state`. It should not perform side effects.

*   **`dispatch` function:**
    *   You call `dispatch({ type: 'SOME_ACTION', payload: someData })` to trigger state updates. React will then call your `reducer` function with the current state and the dispatched action, and update the component's state with the new value returned by the reducer.

## Lazy Initialization:
You can specify the initial state lazily. This lets you extract the initial state calculation into a separate function. It's useful for cases where the initial state is a result of an expensive computation.

`const [state, dispatch] = useReducer(reducer, initialArg, init);`

The `init` function will be called with `initialArg`, and its return value will be used as the initial state.

```jsx
function init(initialCount) {
  return { count: initialCount };
}

function reducer(state, action) { /* ... */ }

function Counter({ initialCount }) {
  const [state, dispatch] = useReducer(reducer, initialCount, init);
  // ...
}
```

## Passing `dispatch` down:
A common pattern is to pass the `dispatch` function down to child components instead of individual callbacks. This avoids prop drilling for actions and ensures child components only need to know how to dispatch actions, not how the state is actually updated. Combined with `useContext`, it's a powerful pattern for global state management.

```jsx
// Context for the dispatch function
const CountDispatchContext = createContext(null);

function App() {
  const [state, dispatch] = useReducer(reducer, initialState);
  return (
    <CountDispatchContext.Provider value={dispatch}>
      <Counter />
    </CountDispatchContext.Provider>
  );
}

function Counter() {
  const dispatch = useContext(CountDispatchContext);
  return (
    <button onClick={() => dispatch({ type: 'increment' })}>Increment</button>
  );
}
```
