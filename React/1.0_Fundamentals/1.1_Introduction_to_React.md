# 1.1 Introduction to React

React is a declarative, efficient, and flexible JavaScript library for building user interfaces. It lets you compose complex UIs from small and isolated pieces of code called "components."

## Key Concepts:
*   **Declarative:** React makes it painless to create interactive UIs. Design simple views for each state in your application, and React will efficiently update and render just the right components when your data changes.
*   **Component-Based:** Build encapsulated components that manage their own state, then compose them to make complex UIs.
*   **Learn Once, Write Anywhere:** React isn't just for the web. It can also be rendered on the server using Node and powered by React Native for building mobile applications.

## How React Works:
React creates a virtual DOM (Document Object Model) in memory. When state changes in a component, React first updates this virtual DOM. Then, it compares the current virtual DOM with the previous one (a process called "diffing") to identify only the necessary changes. Finally, it updates the real DOM efficiently, minimizing direct manipulation and improving performance.

## Prerequisites:
Before diving into React, a good understanding of the following is recommended:
*   HTML, CSS, and JavaScript (ES6+ features)
*   Node.js and npm/yarn (for local development environments)
