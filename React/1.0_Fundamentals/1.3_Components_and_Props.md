# 1.3 Components and Props

Components are the building blocks of any React application. They are independent and reusable pieces of code that return React elements to be rendered to the screen. Components come in two types: Function Components and Class Components.

## Function Components:
Function components are JavaScript functions that accept a single "props" (properties) object argument with data and return a React element.

```jsx
function Welcome(props) {
  return <h1>Hello, {props.name}</h1>;
}
```

This is the most common way to write React components in modern React (since React 16.8 introduced Hooks).

## Class Components:
Class components are ES6 classes that extend `React.Component` and have a `render()` method that returns a React element.

```jsx
class Welcome extends React.Component {
  render() {
    return <h1>Hello, {this.props.name}</h1>;
  }
}
```
While still valid, class components are less common in new React development due to the advantages of function components with Hooks (simplicity, better performance potential, easier to test).

## Rendering a Component:
To render a component, you can use it like an HTML tag in JSX:

```jsx
const element = <Welcome name="Sara" />;
ReactDOM.render(
  element,
  document.getElementById('root')
);
```

## Props (Properties):
Props are a way of passing data from a parent component to a child component. They are read-only, meaning a child component should never modify the props it receives from its parent. This ensures a unidirectional data flow and makes components more predictable.

*   **Read-Only:** "All React components must act like pure functions with respect to their props." This means they should not modify their own props.
*   **Passing Props:** You pass props to components using JSX attributes, just like with HTML attributes.

```jsx
function Avatar(props) {
  return (
    <img className="Avatar"
      src={props.user.avatarUrl}
      alt={props.user.name} />
  );
}

function UserInfo(props) {
  return (
    <div className="UserInfo">
      <Avatar user={props.user} /> {/* Passing user object as a prop */}
      <div className="UserInfo-name">
        {props.user.name}
      </div>
    </div>
  );
}

const user = {
  name: 'Maria',
  avatarUrl: 'https://example.com/maria.jpg',
};

ReactDOM.render(
  <UserInfo user={user} />,
  document.getElementById('root')
);
```

In this example, the `user` object is passed as a prop from `UserInfo` to `Avatar`.

## Props Children:
JSX allows you to pass children directly between the opening and closing tags of a component. These children are then available on the `props.children` property of the component.

```jsx
function FancyBorder(props) {
  return (
    <div className={'FancyBorder FancyBorder-' + props.color}>
      {props.children} {/* Renders whatever is inside FancyBorder tags */}
    </div>
  );
}

function Dialog() {
  return (
    <FancyBorder color="blue">
      <h1 className="Dialog-title">
        Welcome
      </h1>
      <p className="Dialog-message">
        Thank you for visiting our spacecraft!
      </p>
    </FancyBorder>
  );
}
```
Here, `h1` and `p` elements are passed as `children` to `FancyBorder`.
