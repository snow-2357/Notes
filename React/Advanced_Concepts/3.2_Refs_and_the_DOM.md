# 3.2 Refs and the DOM

Refs provide a way to access DOM nodes or React elements created in the `render` method. In the typical React data flow, props are the only way to interact with child components. However, there are a few cases where you need to imperatively modify a child outside of the typical data flow, such as managing focus, text selection, or media playback, triggering imperative animations, or integrating with third-party DOM libraries.

## When to Use Refs:
Refs are generally used for:
*   Managing focus, text selection, or media playback.
*   Triggering imperative animations.
*   Integrating with third-party DOM libraries.

**Avoid using refs for anything that can be done declaratively.** For example, instead of using refs to imperatively change a component's styling, pass props to it.

## Creating Refs:
Refs are created using `React.createRef()` (for class components) or `useRef()` (for functional components).

## 3.2.1 `useRef` Hook (Functional Components)

The `useRef` Hook returns a mutable ref object whose `.current` property is initialized to the passed argument (`initialValue`). The returned ref object will persist for the full lifetime of the component.

**Signature:** `const refContainer = useRef(initialValue);`

```jsx
import React, { useRef } from 'react';

function MyTextInput() {
  const textInput = useRef(null); // Initialize with null

  const focusTextInput = () => {
    // Directly access the DOM node and focus it
    if (textInput.current) {
      textInput.current.focus();
    }
  };

  return (
    <div>
      <input
        type="text"
        ref={textInput} // Attach the ref to the input element
      />
      <button onClick={focusTextInput}>Focus the text input</button>
    </div>
  );
}
```

**Key properties of `useRef`:**
*   **`ref.current`**: The mutable property that holds the current value. It can be updated directly.
*   **Does NOT trigger re-renders**: Unlike `useState`, changing `ref.current` does not cause a component to re-render. This makes it useful for storing any mutable value that doesn't need to trigger a UI update.
*   **Persistence**: The ref object persists across renders; it's not re-created each time the component renders.

## 3.2.2 `React.createRef()` (Class Components - Legacy)

In class components, refs are created in the constructor and attached to elements using the `ref` attribute.

```jsx
import React from 'react';

class MyClassTextInput extends React.Component {
  constructor(props) {
    super(props);
    this.textInput = React.createRef(); // Create a ref
  }

  focusTextInput = () => {
    // Directly access the DOM node and focus it
    this.textInput.current.focus();
  };

  render() {
    return (
      <div>
        <input
          type="text"
          ref={this.textInput} // Attach the ref
        />
        <button onClick={this.focusTextInput}>Focus the text input</button>
      </div>
    );
  }
}
```

## Caveats with Refs:
*   **Don't overdo it:** Use refs sparingly. Most interactions with React components and the DOM should be handled declaratively using props and state.
*   **Function Components can't have `ref` attribute directly:** You cannot use the `ref` attribute on a functional component directly because they don't have instances. If you want to allow parent components to get a ref to the underlying DOM node of your functional component, you need to use `forwardRef`.

## `forwardRef`:
`forwardRef` allows your component to expose a DOM node to a parent component via a ref. This is useful for:
*   Forwarding refs to DOM components (e.g., in a library component).
*   Integrating with higher-order components.

```jsx
import React, { useRef, forwardRef } from 'react';

// A functional component that forwards its ref to the underlying <input>
const FancyInput = forwardRef((props, ref) => (
  <div>
    <input type="text" ref={ref} {...props} />
  </div>
));

function App() {
  const inputRef = useRef(null);

  const handleClick = () => {
    if (inputRef.current) {
      inputRef.current.focus();
    }
  };

  return (
    <>
      <FancyInput ref={inputRef} placeholder="Focus me!" />
      <button onClick={handleClick}>Focus Input</button>
    </>
  );
}
```
In this example, `FancyInput` receives a `ref` from `App` and "forwards" it to its native `<input>` DOM element. This way, `App` can interact directly with the DOM input within `FancyInput`.
