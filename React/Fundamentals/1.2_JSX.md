# 1.2 JSX (JavaScript XML)

JSX is a syntax extension for JavaScript that looks a lot like HTML. It is used with React to describe what the UI should look like. JSX might remind you of a template language, but it comes with the full power of JavaScript.

## Why JSX?
React doesn't *require* JSX, but most React developers find it helpful as a visual aid when working with UI inside JavaScript code. It allows you to write HTML-like structures directly within your JavaScript files, making component rendering logic more intuitive and readable.

## Basic Usage:
You can embed any JavaScript expression inside JSX by enclosing it in curly braces `{}`.

```jsx
const name = 'Josh Perez';
const element = <h1>Hello, {name}</h1>;
// Renders "Hello, Josh Perez"
```

## JSX is an Expression Too:
After compilation, JSX expressions become regular JavaScript function calls and evaluate to JavaScript objects. This means you can use JSX inside `if` statements and `for` loops, assign it to variables, accept it as arguments, and return it from functions.

```jsx
function getGreeting(user) {
  if (user) {
    return <h1>Hello, {user.firstName} {user.lastName}!</h1>;
  }
  return <h1>Hello, Stranger.</h1>;
}
```

## Attributes in JSX:
You can use string literals or JavaScript expressions as attributes.
When using string literals, you pass them in single or double quotes:

```jsx
const element = <a href="https://www.reactjs.org"> Link </a>;
```

When using JavaScript expressions, you wrap them in curly braces:

```jsx
const user = { avatarUrl: 'https://example.com/avatar.jpg' };
const element = <img src={user.avatarUrl}></img>;
```

**Note:** JSX uses `camelCase` for property names instead of HTML attribute names. For example, `class` becomes `className`, and `for` becomes `htmlFor`. This is because `class` and `for` are reserved keywords in JavaScript.

## Children in JSX:
JSX tags can contain children:

```jsx
const element = (
  <div>
    <h1>Hello!</h1>
    <h2>Good to see you here.</h2>
  </div>
);
```

You can also embed JavaScript expressions as children:

```jsx
const data = ['Item 1', 'Item 2', 'Item 3'];
const list = (
  <ul>
    {data.map((item, index) => (
      <li key={index}>{item}</li>
    ))}
  </ul>
);
```
**Key points for children:**
*   **`key` prop:** When rendering lists of elements, you should include a `key` prop for each item. Keys help React identify which items have changed, are added, or are removed. They should be unique among siblings.
*   **Boolean, Null, and Undefined Are Ignored:** `false`, `null`, `undefined`, and `true` are valid children but they don't render anything. This can be useful for conditionally rendering React elements.
    ```jsx
    <div>
      {showHeader && <Header />}
    </div>
    ```
