# 2.7 Custom Hooks

Custom Hooks are a powerful feature in React that allow you to extract reusable stateful logic from a component into a standalone function. They let you reuse logic, not UI, making your components cleaner, more readable, and easier to maintain.

## What is a Custom Hook?
A custom Hook is a JavaScript function whose name starts with "use" and that may call other Hooks. The "use" prefix is a convention that allows React to know that the rules of Hooks (only call at the top level, only call from React functions or other Hooks) apply to it.

## Why Create Custom Hooks?
*   **Code Reusability:** Share stateful logic between multiple components without repeating code.
*   **Separation of Concerns:** Keep your components focused on rendering UI, while the custom Hook handles complex logic.
*   **Readability:** Make complex components easier to understand by abstracting away internal logic.
*   **Testability:** Logic extracted into custom Hooks can be tested more easily in isolation.

## Example: `useCounter`
Let's create a custom Hook to manage a counter.

```jsx
import { useState, useCallback } from 'react';

// Custom Hook: useCounter
function useCounter(initialValue = 0) {
  const [count, setCount] = useState(initialValue);

  const increment = useCallback(() => {
    setCount(prevCount => prevCount + 1);
  }, []); // Empty dependency array means this function reference is stable

  const decrement = useCallback(() => {
    setCount(prevCount => prevCount - 1);
  }, []);

  const reset = useCallback(() => {
    setCount(initialValue);
  }, [initialValue]); // Re-create if initialValue changes

  return { count, increment, decrement, reset };
}

// Component using the custom Hook
function CounterComponent() {
  const { count, increment, decrement, reset } = useCounter(10); // Initial value 10

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={increment}>Increment</button>
      <button onClick={decrement}>Decrement</button>
      <button onClick={reset}>Reset</button>
    </div>
  );
}

// Another component using the same custom Hook
function AnotherCounterComponent() {
  const { count, increment } = useCounter(0); // Starts from 0

  return (
    <div>
      <p>Another Counter: {count}</p>
      <button onClick={increment}>Add One</button>
    </div>
  );
}
```

In this example:
*   `useCounter` is a custom Hook that encapsulates the state (`count`) and the logic (`increment`, `decrement`, `reset`) for a counter.
*   `CounterComponent` and `AnotherCounterComponent` can both use this logic by simply calling `useCounter()`.
*   Each call to `useCounter()` in a component creates an isolated state for that component. They don't share state; they share the *logic* for managing state.

## Custom Hook for Fetching Data: `useFetch`
A common use case for custom Hooks is data fetching.

```jsx
import { useState, useEffect } from 'react';

function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      setLoading(true);
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error(`HTTP error! status: ${response.status}`);
        }
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]); // Re-fetch if URL changes

  return { data, loading, error };
}

function UserProfile({ userId }) {
  const { data: user, loading, error } = useFetch(`https://api.example.com/users/${userId}`);

  if (loading) return <p>Loading user data...</p>;
  if (error) return <p>Error: {error.message}</p>;
  if (!user) return <p>No user found.</p>;

  return (
    <div>
      <h2>{user.name}</h2>
      <p>Email: {user.email}</p>
    </div>
  );
}
```
Here, `useFetch` handles the entire data fetching lifecycle (loading, data, error states). Any component can use `useFetch` to get data by just providing a URL.

## Important Considerations:
*   **Rules of Hooks Still Apply:** Custom Hooks are still Hooks, so they must follow the two rules: only call them at the top level and only call them from React function components or other custom Hooks.
*   **State Isolation:** Each component that uses a custom Hook gets its own isolated state. Custom Hooks are not a way to share state between components directly; they are a way to share stateful *logic*. If you need to share state across components, consider Context API or a dedicated state management library.
*   **Dependencies:** Just like built-in Hooks, if your custom Hook depends on values from the component's scope (props, state), those should be included in the dependency arrays of `useEffect`, `useCallback`, `useMemo` within your custom Hook.
*   **Naming Convention:** Always start your custom Hook function names with `use` (e.g., `useToggle`, `useLocalStorage`). This is how React identifies them as Hooks and applies its rules.
