# 2.4 `useContext` Hook

The `useContext` Hook provides a way to consume values from a React Context. It makes it easier to use the Context API in functional components without the need for a `<Context.Consumer>` component, which often led to prop drilling or wrapper hell.

## What is Context?
React Context provides a way to pass data through the component tree without having to pass props down manually at every level. It's designed to share data that can be considered "global" for a tree of React components, such as the current authenticated user, theme (light/dark), or preferred language.

## Basic Usage:
1.  **Create a Context:** First, you need to create a context using `React.createContext()`. This function returns a Context object.
2.  **Provide a Context Value:** Use the `Context.Provider` component to wrap the part of your component tree where you want to make the context value available. The `value` prop of the provider is the data you want to pass down.
3.  **Consume the Context Value:** Use the `useContext` Hook in any functional component within the provider's subtree to read the current context value.

```jsx
// 1. Create the Context
import React, { createContext, useContext, useState } from 'react';

const ThemeContext = createContext(null); // Default value

// 2. Provide the Context Value
function ThemeProvider({ children }) {
  const [theme, setTheme] = useState('light'); // 'light' or 'dark'

  const toggleTheme = () => {
    setTheme(prevTheme => (prevTheme === 'light' ? 'dark' : 'light'));
  };

  const contextValue = { theme, toggleTheme };

  return (
    <ThemeContext.Provider value={contextValue}>
      {children}
    </ThemeContext.Provider>
  );
}

// 3. Consume the Context Value
function ThemeToggleButton() {
  const { theme, toggleTheme } = useContext(ThemeContext);

  return (
    <button onClick={toggleTheme} style={{
      background: theme === 'light' ? '#eee' : '#333',
      color: theme === 'light' ? '#333' : '#eee',
      border: `1px solid ${theme === 'light' ? '#333' : '#eee'}`,
      padding: '10px',
      borderRadius: '5px',
      cursor: 'pointer'
    }}>
      Current Theme: {theme} (Click to toggle)
    </button>
  );
}

// Parent component that uses the provider
function App() {
  return (
    <ThemeProvider>
      <Toolbar />
    </ThemeProvider>
  );
}

// A component somewhere in the middle that doesn't need the theme itself
function Toolbar() {
  return (
    <div>
      <ThemeToggleButton />
    </div>
  );
}

// To render the App:
// ReactDOM.render(<App />, document.getElementById('root'));
```

## `useContext(MyContext)`:
*   `useContext(MyContext)` returns the current context value for that context.
*   The argument to `useContext` must be the context object itself (the value returned from `React.createContext()`), not the `Consumer` or `Provider`.
*   When the closest `Provider` above the component updates, this Hook will trigger a re-render with the latest context value.

## When to Use Context:
Context is great for sharing data that is considered "global" for a component tree. However, it's not a replacement for all forms of state management. For complex application-wide state, you might still consider dedicated state management libraries (like Redux, Zustand, Recoil, Jotai).

Using `useContext` can simplify your code by eliminating the need to pass props down through many levels of nested components, a pattern often referred to as "prop drilling."
