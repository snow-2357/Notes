# 5.1 Profiling with Lighthouse and DevTools

To optimize your application, you first need to measure it. Profiling is the process of analyzing your application to identify performance bottlenecks.

## Chrome DevTools: The Performance Tab

The Performance tab in Chrome's DevTools is the most powerful tool for understanding what your site is doing at any given moment.

**How to use it:**
1.  Open Chrome DevTools (`Cmd+Opt+I` or `F12`).
2.  Go to the "Performance" tab.
3.  Click the "Record" button and interact with your page (or reload it).
4.  Click "Stop."

**What to look for:**
- **Main Thread Activity:** A flame chart shows you exactly which functions were called and how long they took. Long, solid blocks of color are "Long Tasks" that can block the main thread and make your page unresponsive.
- **Frames Per Second (FPS):** Look for red bars in the FPS chart, which indicate dropped frames and janky animations.
- **Network:** See when assets are being loaded.
- **Timings:** Key metrics like First Contentful Paint (FCP), Largest Contentful Paint (LCP), and DOMContentLoaded are marked on the timeline.

## Lighthouse

Lighthouse is an open-source, automated tool for improving the quality of web pages. It's built directly into Chrome DevTools.

**How to use it:**
1.  Open Chrome DevTools.
2.  Go to the "Lighthouse" tab.
3.  Choose the categories you want to audit (Performance, Accessibility, Best Practices, SEO).
4.  Click "Analyze page load."

Lighthouse will generate a report with a score from 0-100 for each category. For performance, it measures key metrics and provides actionable advice.

### Key Performance Metrics (Web Vitals)

- **Largest Contentful Paint (LCP):** Measures *loading* performance. The time it takes for the largest image or text block visible within the viewport to be rendered. (Good: < 2.5s)
- **First Input Delay (FID) / Interaction to Next Paint (INP):** Measures *interactivity*. FID measures the time from when a user first interacts with a page to the time when the browser is actually able to begin processing event handlers in response to that interaction. INP is a newer, more comprehensive metric that will replace FID. (Good FID: < 100ms)
- **Cumulative Layout Shift (CLS):** Measures *visual stability*. It quantifies how much unexpected layout shift (e.g., an ad loading and pushing content down) occurs during the lifespan of the page. (Good: < 0.1)

Lighthouse provides specific "Opportunities" and "Diagnostics" to help you improve these scores, such as "Eliminate render-blocking resources," "Properly size images," and "Reduce initial server response time."
