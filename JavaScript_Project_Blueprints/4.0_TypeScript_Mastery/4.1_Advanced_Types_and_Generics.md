# 4.1 Advanced Types and Generics

This note covers some of the more powerful features of TypeScript that allow for creating flexible, reusable, and strongly-typed code.

## Utility Types
TypeScript provides several built-in utility types to facilitate common type transformations.

- **`Partial<T>`:** Constructs a type with all properties of `T` set to optional. Useful for update operations.
- **`Required<T>`:** Constructs a type with all properties of `T` set to required.
- **`Readonly<T>`:** Constructs a type with all properties of `T` set to `readonly`.
- **`Pick<T, K>`:** Constructs a type by picking the set of properties `K` from `T`.
- **`Omit<T, K>`:** Constructs a type by picking all properties from `T` and then removing `K`.
- **`Record<K, T>`:** Constructs an object type with a set of properties `K` of type `T`.

## Advanced Types

- **Union Types (`|`):** A type that can be one of several types. `string | number`.
- **Intersection Types (`&`):** Combines multiple types into one. `HasName & HasAge`.
- **Conditional Types:** Selects one of two possible types based on a condition.
    ```typescript
    type IsString<T> = T extends string ? "yes" : "no";
    type A = IsString<string>; // "yes"
    type B = IsString<number>; // "no"
    ```
- **Mapped Types:** Creates a new type by iterating over the properties of an existing type. `Partial`, `Required`, and `Readonly` are implemented using mapped types.
    ```typescript
    type Stringify<T> = {
      [P in keyof T]: string;
    };
    ```

## Generics
Generics allow you to write a function or a type that can work over a variety of types rather than a single one. This is a cornerstone of reusable code.

### Generic Functions
```typescript
// This function can accept any type and will return that same type.
function identity<T>(arg: T): T {
    return arg;
}

let output = identity<string>("myString"); // type of output is 'string'
let output2 = identity(100); // type is inferred as 100
```

### Generic Interfaces & Classes
```typescript
interface GenericResponse<T> {
    data: T;
    status: number;
}

function processResponse(response: GenericResponse<{ id: number; name: string }>) {
    console.log(response.data.name);
}
```

### Generic Constraints
You can use constraints to limit the types that a generic type parameter can accept.

```typescript
interface Lengthwise {
    length: number;
}

// We constrain T to be a type that has a .length property.
function loggingIdentity<T extends Lengthwise>(arg: T): T {
    console.log(arg.length);
    return arg;
}
```
Mastering these advanced features allows you to model complex data structures and APIs with a high degree of type safety.
