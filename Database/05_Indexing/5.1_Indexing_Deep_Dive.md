# Phase 5: Indexing (The Heart of Performance)

Indexing is what separates a developer from a backend engineer. It's the difference between a 10ms query and a 10s query.

## 1. What is an Index?
An index is a separate data structure (usually a B-Tree) that stores a sorted version of your column(s) with pointers (CTIDs) to the actual rows.

### 1.1 Why use them?
- **Speed Reads:** `O(log N)` vs `O(N)` for full table scans.
- **Slow Writes:** Every `INSERT/UPDATE/DELETE` requires the DB to update the index tree, adding overhead.

## 2. Index Types
- **B-Tree (Default):** Balanced tree. Best for equality (`=`) and range (`>`, `<`) queries.
- **Hash Index:** Only for equality (`=`). Fast but limited.
- **Composite Index:** An index on multiple columns `(A, B)`. 
    - *Rule of Thumb:* The order of columns matters (Left-to-Right rule).
- **Clustered Index:** Defines the physical order of data on disk (usually the PK).
- **Non-Clustered:** Separate structure with pointers to the heap.
- **Covering Index:** An index that includes all columns in the `SELECT`, allowing the DB to skip the heap fetch entirely.
- **Partial Index:** Indexing only a subset of data (e.g., `WHERE status = 'active'`).
- **Unique Index:** Ensures no two rows have the same value while also providing search speed.

## 3. Critical Performance Concepts

### 3.1 Cardinality vs Selectivity
- **Cardinality:** The number of unique values in a column.
- **Selectivity:** `(Number of unique values) / (Total number of rows)`.
- *Rule:* High selectivity = Good index. Low selectivity (e.g., a "Gender" column) = Database will likely ignore the index and do a Full Table Scan.

### 3.2 The N+1 Query Problem
When you fetch a list of items and then perform a separate query for each item's related data.
- *Solution:* Use `JOIN` or `IN (...)`.

### 3.3 Query Planner & Diagnostics
- **Full Table Scan:** The DB reads every page of the table. Usually bad for large tables.
- **EXPLAIN ANALYZE:** The most important command for a DBA. It shows the execution plan and actual timing.
    - *Look for:* "Seq Scan", "Filter", "Actual Time".
