# Phase 2 & 3: SQL Mastery (Basics to Intermediate)

A guide to writing efficient and readable SQL.

## 1. SQL Basics (The Foundational Blocks)
- `SELECT`: Choose your columns.
- `WHERE`: Filter your rows.
- `ORDER BY`: Sort your data (ASC/DESC).
- `GROUP BY`: Aggregate rows (Sum, Avg, Count).
- `HAVING`: Filter groups (used with GROUP BY).
- `LIMIT/OFFSET`: Pagination basics.
- `DISTINCT`: Remove duplicates.
- `CASE WHEN`: If-else logic in SQL.

## 2. SQL Intermediate (The Developer's Core)

### 2.1 Joins
- **INNER JOIN:** Matches in both tables.
- **LEFT JOIN:** All from left table, matches from right.
- **RIGHT JOIN:** All from right table, matches from left.
- **SELF JOIN:** Joining a table to itself (Hierarchies).
- **CROSS JOIN:** Cartesian product.

### 2.2 Sets & Subqueries
- **UNION vs UNION ALL:** Combining result sets (UNION removes duplicates).
- **Subqueries:** Queries inside queries.
- **Correlated Subqueries:** Inner query depends on the outer query.
- **EXISTS:** Check for existence of rows in subquery.

### 2.3 CTEs (Common Table Expressions)
Temporary result sets that improve readability.
```sql
WITH regional_sales AS (
    SELECT region, SUM(amount) AS total
    FROM orders GROUP BY region
)
SELECT * FROM regional_sales WHERE total > 10000;
```

### 2.4 Window Functions (Analytical Power)
Perform calculations across related rows.
- `ROW_NUMBER()`: Unique sequence.
- `RANK()` / `DENSE_RANK()`: Ranking with/without gaps.
- `LEAD()` / `LAG()`: Access next/previous rows.
