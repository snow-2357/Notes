# The Database Masterclass: Engineering Roadmap

This collection is structured as a 15-phase curriculum to take you from a SQL beginner to a senior database architect.

## 🗺️ The 15 Phases

### [Phase 1: Database Fundamentals](./01_Database_Fundamentals/)
*   DBMS vs RDBMS, Tables/Rows/Columns, Primary & Foreign Keys, Constraints, Normalization (1NF to BCNF), ACID Properties, CAP Theorem.

### [Phase 2: SQL Basics](./02_SQL_Basics/)
*   Core Syntax: SELECT, WHERE, ORDER BY, GROUP BY, HAVING, LIMIT/OFFSET, DISTINCT, CASE WHEN.
*   *Practice: Employee & Ecommerce Schemas.*

### [Phase 3: SQL Intermediate](./03_SQL_Intermediate/)
*   Joins (Inner, Left, Right, Self, Cross), Unions, Subqueries, CTEs, Window Functions (Rank, Lead/Lag), Views, Stored Procedures.

### [Phase 4: SQL Advanced](./04_SQL_Advanced/)
*   Query Optimization, Execution Plans, Recursive CTEs, Transactions, Locks, Deadlocks, Isolation Levels (Read Committed to Serializable).

### [Phase 5: Indexing (The Heart of Performance)](./05_Indexing/)
*   B-Tree vs Hash vs GIN, Composite/Covering/Partial Indexes, Cardinality, Selectivity, N+1 Query Problem, EXPLAIN ANALYZE.

### [Phase 6: Database Design](./06_Database_Design/)
*   Entity Relationships (1:1, 1:M, M:M), Junction Tables, Audit Trails, Soft Deletes, Versioning, Design for Ecommerce/Social/Chat/Banking.

### [Phase 7: Transactions & Concurrency](./07_Transactions_and_Concurrency/)
*   Atomicity, Rollbacks, Row-level Locks, Optimistic vs Pessimistic Locking, MVCC (xmin/xmax), Race Conditions, Double Spending Problem.

### [Phase 8: Scaling](./08_Scaling/)
*   Vertical vs Horizontal Scaling, Replication (Master-Slave/Leader-Follower), Read Replicas, Connection Pooling (PgBouncer), Caching (Redis).

### [Phase 9: Partitioning & Sharding](./09_Partitioning_and_Sharding/)
*   Range/Hash/List Partitioning, Shard Keys, Consistent Hashing, Hot Partitions, Distributed Transactions, Replication Lag.

### [Phase 10: NoSQL Databases](./10_NoSQL_Databases/)
*   Document (Mongo), Key-Value (Redis), Wide-column (Cassandra), Graph (Neo4j), Schema-less Design, Eventual Consistency.

### [Phase 11: Distributed Systems Concepts](./11_Distributed_Systems_Concepts/)
*   Consensus (Raft), Quorum R/W, Strong vs Eventual Consistency, Distributed Locks, PACELC Theorem.

### [Phase 12: Performance Optimization](./12_Performance_Optimization/)
*   Slow Query Analysis, Materialized Views, Bulk Inserts, Pagination (Offset vs Cursor), Connection Pool Tuning.

### [Phase 13: Real World Data Patterns](./13_Real_World_Data_Patterns/)
*   Event Sourcing, CQRS, Outbox Pattern, Idempotency, Append-only Logs, Time-series Storage.

### [Phase 14: Database Security](./14_Database_Security/)
*   SQL Injection, Prepared Statements, Row-level Security (RLS), Encryption at rest/transit, Backup & Recovery.

### [Phase 15: Database Internals (Senior Level)](./15_Database_Internals/)
*   B-Tree implementation, WAL (Write Ahead Log), LSM Trees, SSTables, Buffer Pool, Vacuuming/Checkpointing.
