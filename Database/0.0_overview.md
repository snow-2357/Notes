### Core Concepts Quick-View

| Concept | Description | Key Tech |
| :--- | :--- | :--- |
| **Indexing** | Faster data retrieval using balanced trees. | B-Trees, Hash, GIN |
| **Sharding** | Distributing data across multiple server nodes. | Citus, Vitess |
| **MVCC** | Handling concurrency without locking. | PostgreSQL, MySQL (InnoDB) |
| **ACID** | Atomicity, Consistency, Isolation, Durability. | Relational DBs |
