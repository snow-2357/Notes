# Dunder Methods in Python

Dunder methods, short for "double underscore" methods (also known as "magic methods"), are special methods in Python that are surrounded by double underscores, like `__init__` or `__str__`. They allow you to define how your objects behave with built-in Python features.

You don't typically call dunder methods directly (e.g., `my_obj.__str__()`). Instead, they are invoked by a corresponding built-in function or operation (e.g., `str(my_obj)`).

## 1. Object Initialization: `__init__`

This is the most common dunder method. It's the constructor for a class, called when you create a new instance of that class.

```python
class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author
```

## 2. String Representation: `__str__` and `__repr__`

- **`__str__`**: Called by the `str()` built-in function and by `print()`. It should return a "user-friendly" string representation of the object.
- **`__repr__`**: Called by the `repr()` built-in function. It should return an "official" string representation of the object, which is ideally unambiguous and could be used to recreate the object. If `__str__` is not defined, `__repr__` is used as a fallback.

```python
class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author

    def __str__(self):
        return f"'{self.title}' by {self.author}"

    def __repr__(self):
        return f"Book(title='{self.title}', author='{self.author}')"

book = Book("The Hobbit", "J.R.R. Tolkien")

print(book)        # Calls __str__ -> 'The Hobbit' by J.R.R. Tolkien
print(str(book))   # Calls __str__
print(repr(book))  # Calls __repr__ -> Book(title='The Hobbit', author='J.R.R. Tolkien')
```

## 3. Length: `__len__`

Called by the `len()` built-in function. It should return the length of the container.

```python
class Library:
    def __init__(self):
        self.books = []

    def add_book(self, book):
        self.books.append(book)

    def __len__(self):
        return len(self.books)

lib = Library()
lib.add_book(book)
print(len(lib)) # Output: 1
```

## 4. Comparison Operators

You can define how comparison operators like `==`, `!=`, `<`, `>`, etc., work for your objects.

- `__eq__(self, other)`: Defines behavior for the equality operator, `==`.
- `__ne__(self, other)`: Defines behavior for the inequality operator, `!=`.
- `__lt__(self, other)`: Defines behavior for the less-than operator, `<`.
- `__gt__(self, other)`: Defines behavior for the greater-than operator, `>`.

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __eq__(self, other):
        return self.title == other.title and self.pages == other.pages

    def __gt__(self, other):
        return self.pages > other.pages

book1 = Book("Book A", 200)
book2 = Book("Book B", 300)
book3 = Book("Book A", 200)

print(book1 == book3) # True, because __eq__ is defined
print(book2 > book1)  # True, because __gt__ is defined
```

## 5. Arithmetic Operators

You can also define how arithmetic operators work.
- `__add__(self, other)`: For `+`.
- `__sub__(self, other)`: For `-`.
- `__mul__(self, other)`: For `*`.

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(2, 4)
v2 = Vector(3, 5)
v3 = v1 + v2 # __add__ is called here
print(v3) # Output: Vector(5, 9)
```
