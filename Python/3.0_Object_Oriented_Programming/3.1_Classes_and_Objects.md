# Classes and Objects in Python

Python is an object-oriented programming language. Almost everything in Python is an object, with its properties and methods.

## 1. Classes

A class is like a blueprint for creating objects. It defines a set of attributes (properties) and methods (functions) that the created objects will have.

### Creating a Class
We use the `class` keyword to create a class. Class names are conventionally written in `PascalCase`.

```python
class Dog:
    # This is a class attribute, shared by all instances of the class
    species = "Canis familiaris"

    # This is the constructor method, called when a new object is created
    def __init__(self, name, age):
        # These are instance attributes, unique to each instance
        self.name = name
        self.age = age

    # This is an instance method
    def bark(self):
        print("Woof!")

    # Another instance method that uses instance attributes
    def describe(self):
        return f"{self.name} is {self.age} years old."
```

- **`__init__` method**: This special method, also called a constructor, is automatically called when you create a new instance of the class. It initializes the object's attributes. The `self` parameter is a reference to the current instance of the class and is used to access variables that belong to the class.

## 2. Objects (Instances)

An object is an instance of a class. You can create multiple objects from a single class blueprint.

### Creating an Object
You create an object by calling the class name as if it were a function.

```python
# Creating two 'Dog' objects
my_dog = Dog("Buddy", 3)
your_dog = Dog("Lucy", 5)
```

### Accessing Attributes and Methods

You can access an object's attributes and methods using the dot (`.`) notation.

```python
# Accessing instance attributes
print(my_dog.name)   # Output: Buddy
print(your_dog.age)  # Output: 5

# Accessing the class attribute
print(my_dog.species) # Output: Canis familiaris

# Calling instance methods
my_dog.bark()                   # Output: Woof!
description = your_dog.describe()
print(description)              # Output: Lucy is 5 years old.
```

## The `self` Parameter

The `self` parameter is a reference to the instance of the class. It must be the first parameter of any method in the class. When you call a method like `my_dog.bark()`, Python automatically passes the `my_dog` object as the `self` argument. You do not need to provide it yourself.

## Modifying Object Properties

You can modify the properties of an object after it has been created.

```python
my_dog.age = 4
print(my_dog.describe()) # Output: Buddy is 4 years old.
```
