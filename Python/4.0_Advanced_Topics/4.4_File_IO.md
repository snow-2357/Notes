# File I/O in Python

File I/O (Input/Output) refers to reading from and writing to files. Python provides a simple and powerful way to interact with files.

## 1. Opening a File

The `open()` function is used to open a file. It returns a file object and is most commonly used with two arguments: `open(filename, mode)`.

- **filename**: The name of the file you want to open.
- **mode**: A string that specifies how the file should be opened.

### Common File Modes

| Mode | Description                                                 |
| :--- | :---------------------------------------------------------- |
| `'r'`  | **Read** (default mode). Opens a file for reading, error if the file does not exist. |
| `'w'`  | **Write**. Opens a file for writing, creates the file if it does not exist, or truncates (empties) the file if it exists. |
| `'a'`  | **Append**. Opens a file for appending, creates the file if it does not exist. New data is written to the end of the file. |
| `'x'`  | **Create**. Creates the specified file, returns an error if the file exists. |
| `'+'`  | Can be added to a mode (e.g., `'r+'`, `'w+'`) to open the file for both reading and writing (updating). |
| `'b'`  | **Binary mode** (e.g., `'rb'`, `'wb'`). For handling binary files like images or executables. |
| `'t'`  | **Text mode** (default). For handling text files.          |


## 2. The `with` Statement (Recommended)

The recommended way to work with files is by using the `with` statement. It ensures that the file is automatically closed when the block inside the `with` statement is exited, even if an error occurs.

```python
# Writing to a file
with open("my_file.txt", "w") as f:
    f.write("Hello, World!\n")
    f.write("This is a second line.\n")

# Reading from a file
with open("my_file.txt", "r") as f:
    content = f.read()
    print(content)
```

## 3. Reading from Files

There are several ways to read content from a file.

### `read()`
Reads the entire content of the file as a single string.

```python
with open("my_file.txt", "r") as f:
    all_content = f.read()
```

### `readline()`
Reads a single line from the file, including the newline character `\n` at the end.

```python
with open("my_file.txt", "r") as f:
    first_line = f.readline()
    second_line = f.readline()
```

### `readlines()`
Reads all the lines from the file and returns them as a list of strings.

```python
with open("my_file.txt", "r") as f:
    all_lines = f.readlines()
    # all_lines will be ['Hello, World!\n', 'This is a second line.\n']
```

You can also iterate over the file object directly, which is a memory-efficient way to read a file line by line.

```python
with open("my_file.txt", "r") as f:
    for line in f:
        print(line, end="") # The 'end=""' prevents double newlines
```

## 4. Writing to Files

### `write()`
Writes a string to the file. It does not add a newline character automatically.

```python
with open("greetings.txt", "w") as f:
    f.write("Hello\n")
    f.write("Bonjour\n")
```

### `writelines()`
Writes a list of strings to the file. It does not add newline characters, so you need to include them in your strings.

```python
lines = ["First line\n", "Second line\n", "Third line\n"]
with open("output.txt", "w") as f:
    f.writelines(lines)
```
