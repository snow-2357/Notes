# Modules and Packages in Python

As your program gets larger, it is important to organize it into logical blocks. Python provides modules and packages for this.

## 1. Modules

A module is simply a Python file (`.py`) with code inside. You can use modules to break down large programs into smaller, manageable, and organized files.

Let's say we have a file named `my_module.py`:
```python
# my_module.py

def greet(name):
    return f"Hello, {name}!"

PI = 3.14159
```

### Importing a Module
You can use the `import` statement to use the code from one module in another file.

```python
# main.py

import my_module

print(my_module.greet("Alice")) # Output: Hello, Alice!
print(my_module.PI)             # Output: 3.14159
```

### Importing Specific Parts of a Module
You can import only specific functions or variables using the `from ... import ...` statement.

```python
# main.py

from my_module import greet, PI

print(greet("Bob")) # No need to use 'my_module.' prefix
print(PI)
```

### Importing with an Alias
You can import a module with a different name (an alias) to make it shorter or to avoid name conflicts.

```python
# main.py

import my_module as mm

print(mm.greet("Charlie"))
```

## 2. Packages

A package is a way of organizing related modules into a directory hierarchy. A directory is treated as a package if it contains a special file named `__init__.py`. This file can be empty.

Consider this directory structure:
```
my_app/
├── __init__.py
├── module1.py
└── subpackage/
    ├── __init__.py
    └── module2.py
```

- `my_app` is a package.
- `subpackage` is a sub-package.
- `__init__.py` files tell Python that these directories are packages.

### `__init__.py`
This file is executed when the package is imported. It can be used to initialize package-level data or to make certain modules available for easier import.

For example, in `my_app/__init__.py`:
```python
# my_app/__init__.py
print("my_app package is being imported")
```

### Importing from Packages
You use the dot notation to import modules from packages.

```python
# main.py

# Import module1 from the my_app package
import my_app.module1

# Import module2 from the subpackage
from my_app.subpackage import module2

# You can also do relative imports from within the package itself
# For example, inside module1.py, you could write:
# from .subpackage import module2 # '.' means from the current package
```

## 3. The Python Standard Library

Python comes with a huge standard library, which is a collection of modules for common tasks. You don't need to install anything extra to use them.

```python
# Using the 'math' module for more advanced math functions
import math

print(math.sqrt(16)) # Output: 4.0

# Using the 'datetime' module to work with dates and times
import datetime

now = datetime.datetime.now()
print(now)
```
This extensive library is one of Python's greatest strengths.
