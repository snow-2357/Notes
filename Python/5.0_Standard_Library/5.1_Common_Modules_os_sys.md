# Common Standard Library Modules: `os` and `sys`

The Python Standard Library contains a vast number of modules for a wide range of tasks. `os` and `sys` are two fundamental modules for interacting with the operating system and the Python interpreter environment.

## 1. The `os` Module

The `os` module provides a portable way of using operating system-dependent functionality.

### Interacting with the Filesystem

- **`os.getcwd()`**: Get the current working directory.
- **`os.chdir(path)`**: Change the current working directory.
- **`os.listdir(path)`**: Returns a list of all files and directories in the specified directory.
- **`os.mkdir(path)`**: Creates a single directory.
- **`os.makedirs(path)`**: Creates directories recursively (e.g., `path/to/new/folder`).
- **`os.remove(path)`**: Deletes a file.
- **`os.rmdir(path)`**: Deletes an empty directory.
- **`os.rename(src, dst)`**: Renames a file or directory.

```python
import os

# Get current directory
cwd = os.getcwd()
print(f"Current Directory: {cwd}")

# List files and directories
print(f"Contents: {os.listdir('.')}")
```

### The `os.path` Submodule
This submodule provides functions for working with file paths in a portable way.

- **`os.path.join(path, *paths)`**: Joins path components intelligently. This is the recommended way to create file paths.
- **`os.path.exists(path)`**: Checks if a path exists.
- **`os.path.isfile(path)`**: Checks if a path is a file.
- **`os.path.isdir(path)`**: Checks if a path is a directory.
- **`os.path.splitext(path)`**: Splits a path into `(root, ext)`.

```python
import os

# Create a path safely
file_path = os.path.join(os.getcwd(), 'data', 'my_file.txt')
print(f"Full path: {file_path}")

# Check if path exists
print(f"Exists? {os.path.exists(file_path)}")
```

### Accessing Environment Variables

- **`os.environ`**: A dictionary-like object where you can access environment variables.
- **`os.getenv(key)`**: A safer way to get an environment variable; it returns `None` if the key doesn't exist.

```python
import os

# Get the value of the 'PATH' environment variable
path_var = os.getenv('PATH')
# print(path_var)
```

## 2. The `sys` Module

The `sys` module provides access to system-specific parameters and functions that are managed by the Python interpreter.

### Command-Line Arguments: `sys.argv`
A list of command-line arguments passed to a Python script. `sys.argv[0]` is the script name itself.

Suppose you run a script like this: `python my_script.py arg1 arg2`

```python
# my_script.py
import sys

print(f"Script name: {sys.argv[0]}")
print(f"Arguments: {sys.argv[1:]}")
```

### Interpreter Information
- **`sys.version`**: The version of the Python interpreter.
- **`sys.platform`**: The platform identifier (e.g., 'linux', 'win32', 'darwin' for macOS).
- **`sys.path`**: A list of strings that specifies the search path for modules. You can modify this list to change where Python looks for modules.

```python
import sys

print(f"Python version: {sys.version}")
print(f"Platform: {sys.platform}")
```

### Exiting the Script: `sys.exit()`
Terminates the current script. You can optionally pass an exit code (an integer or another object). An exit code of `0` is considered a "successful termination."

```python
import sys

if sys.platform != 'linux':
    print("This script is intended for Linux.")
    sys.exit(1) # Exit with an error code

print("Running on Linux...")
```
