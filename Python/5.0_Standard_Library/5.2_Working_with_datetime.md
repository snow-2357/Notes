# Working with `datetime`

The `datetime` module supplies classes for working with dates and times.

## 1. `date` Objects

A `date` object represents a date (year, month, and day).

```python
import datetime

# Create a date object
d = datetime.date(2023, 10, 26)
print(d) # Output: 2023-10-26

# Get the current date
today = datetime.date.today()
print(f"Today is {today}")

# Access attributes
print(f"Year: {today.year}, Month: {today.month}, Day: {today.day}")

# Get weekday (Monday is 0 and Sunday is 6)
print(f"Weekday: {today.weekday()}")
```

## 2. `time` Objects

A `time` object represents a time of day (hour, minute, second, microsecond).

```python
import datetime

t = datetime.time(9, 30, 45)
print(t) # Output: 09:30:45

# Access attributes
print(f"Hour: {t.hour}, Minute: {t.minute}")
```

## 3. `datetime` Objects

A `datetime` object is a combination of a date and a time.

```python
import datetime

# Create a datetime object
dt = datetime.datetime(2023, 10, 26, 9, 30)
print(dt) # Output: 2023-10-26 09:30:00

# Get the current date and time
now = datetime.datetime.now()
print(f"Now: {now}")

# Get today's date with current time
today_now = datetime.datetime.today()

# Get UTC time
utc_now = datetime.datetime.utcnow()
print(f"UTC Now: {utc_now}")
```

## 4. `timedelta` Objects

A `timedelta` object represents a duration, the difference between two dates or times. It's useful for performing date arithmetic.

```python
import datetime

now = datetime.datetime.now()

# Create a timedelta representing 10 days
ten_days = datetime.timedelta(days=10)

# What will be the date in 10 days?
date_in_10_days = now + ten_days
print(f"10 days from now: {date_in_10_days}")

# What was the date 3 weeks ago?
three_weeks = datetime.timedelta(weeks=3)
date_3_weeks_ago = now - three_weeks
print(f"3 weeks ago: {date_3_weeks_ago}")

# Timedeltas can be used for differences
delta = date_in_10_days - now
print(f"Difference: {delta.total_seconds()} seconds")
```

## 5. Formatting and Parsing (`strftime` and `strptime`)

### `strftime` - Format `datetime` to String
Converts a `datetime` object to a string according to a specified format.

Common format codes:
- `%Y`: Year with century (e.g., 2023)
- `%y`: Year without century (e.g., 23)
- `%m`: Month as a zero-padded decimal number (01-12)
- `%d`: Day of the month (01-31)
- `%H`: Hour (24-hour clock) (00-23)
- `%I`: Hour (12-hour clock) (01-12)
- `%M`: Minute (00-59)
- `%S`: Second (00-61)
- `%p`: AM or PM
- `%A`: Weekday as full name (e.g., Sunday)
- `%a`: Weekday as abbreviated name (e.g., Sun)

```python
import datetime

now = datetime.datetime.now()

# Format the datetime into a string
formatted_string = now.strftime("%Y-%m-%d %H:%M:%S")
print(formatted_string) # e.g., "2023-10-26 10:30:55"

formatted_string_2 = now.strftime("%A, %d %B %Y")
print(formatted_string_2) # e.g., "Thursday, 26 October 2023"
```

### `strptime` - Parse String to `datetime`
Parses a string representing a date and time into a `datetime` object.

```python
import datetime

date_string = "2023-10-26 12:45:00"
format_code = "%Y-%m-%d %H:%M:%S"

# Convert the string to a datetime object
datetime_object = datetime.datetime.strptime(date_string, format_code)

print(datetime_object)
print(datetime_object.year)
```
The format code passed to `strptime` must match the format of the date string exactly.
