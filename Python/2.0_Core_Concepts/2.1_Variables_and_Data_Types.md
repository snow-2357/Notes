# Variables and Data Types in Python

In Python, variables are created when you first assign a value to them. Python is dynamically typed, which means you don't need to declare the type of a variable.

## 1. Variables

A variable is a container for a value.

```python
# A variable named 'x' holding an integer value
x = 10

# A variable named 'name' holding a string value
name = "Alice"

# You can change the type of a variable
x = "Now I'm a string"
```

### Type Hinting (Modern Python)

Since Python 3.5+, you can add "type hints" to your variables. These are optional and don't affect how the code runs, but they make your code easier to read and help tools find errors.

```python
age: int = 30
name: str = "Bob"
is_student: bool = True
```

---

## 2. Mutability and Immutability

This is a fundamental concept in Python.

- **Immutable types**: Their value cannot be changed after they are created. If you try to "change" them, you are actually creating a new object in memory.
  - Examples: `int`, `float`, `str`, `tuple`, `bool`, `None`
- **Mutable types**: Their value can be changed in place without creating a new object.
  - Examples: `list`, `dict`, `set`

```python
# Strings are immutable
my_string = "hello"
# my_string[0] = "H"  # This will raise a TypeError

# Lists are mutable
my_list = [1, 2, 3]
my_list[0] = 100  # This is perfectly fine
print(my_list)  # Output: [100, 2, 3]
```

## 3. Common Data Types In-Depth

### Numeric Types

- **int**: Integer numbers (e.g., `10`, `-5`, `1000`).
- **float**: Floating-point numbers (e.g., `3.14`, `-0.5`).

```python
age = 30           # int
price = 19.99      # float

# You can perform arithmetic operations
sum_of_ages = age + 5   # 35
new_price = price * 1.2 # 23.988
```

### Text Type: `str`

A sequence of characters, enclosed in single, double, or triple quotes. Strings are immutable.

```python
greeting = "Hello, World!"
multiline_string = """This is a string
that spans multiple lines."""
```

**Common String Operations:**

- **Concatenation**: Joining strings together.
  ```python
  first_name = "John"
  last_name = "Doe"
  full_name = first_name + " " + last_name
  print(full_name) # "John Doe"
  ```

- **f-strings (Formatted String Literals)**: A modern and clean way to embed expressions inside string literals.
  ```python
  name = "Jane"
  age = 28
  print(f"{name} is {age} years old.") # "Jane is 28 years old."
  ```

- **Slicing**: Extracting a part of a string.
  ```python
  s = "Programming"
  print(s[0:4])   # "Prog"
  print(s[4:])    # "ramming"
  print(s[-1])    # "g" (last character)
  ```

- **Common Methods**:
  ```python
  s = "  Hello Python  "
  print(s.upper())      # "  HELLO PYTHON  "
  print(s.lower())      # "  hello python  "
  print(s.strip())      # "Hello Python" (removes leading/trailing whitespace)
  print(s.split('o'))   # ['  Hell', ' Pyth', 'n  ']
  ```

### Sequence Types

#### `list`: An ordered and mutable (changeable) collection. Allows duplicate members.

```python
# A list of numbers
my_list = [1, 2, 3, "apple"]
my_list.append(4) # Add an item to the end
my_list.pop()     # Remove the last item
my_list[3] = "banana" # Modify an item by index
print(my_list) # [1, 2, 3, 'banana']
```

#### `tuple`: An ordered and immutable (unchangeable) collection. Allows duplicate members.

Tuples are often used for fixed collections of items, like coordinates.

```python
# A tuple of coordinates
point = (10, 20)

# You can "unpack" tuples
x, y = point
print(f"x={x}, y={y}") # "x=10, y=20"
```

### Mapping Type: `dict`

A collection of key-value pairs. It is mutable and does not allow duplicate keys. As of Python 3.7, dictionaries are ordered.

```python
# A dictionary representing a person
person = {
    "name": "Bob",
    "age": 25,
    "city": "New York"
}

# Accessing a value
print(person["name"]) # "Bob"

# Adding or updating a value
person["job"] = "Developer" # Add a new key-value pair
person["age"] = 26          # Update an existing value

# Removing a value
del person["city"]

print(person) # {'name': 'Bob', 'age': 26, 'job': 'Developer'}
```

### Set Types: `set`

An unordered, mutable, and unindexed collection of unique elements. Useful for membership testing and eliminating duplicate entries.

```python
# A set of unique numbers
my_set = {1, 2, 3, 3, 4}
my_set.add(5)
my_set.remove(2)
print(my_set) # {1, 3, 4, 5}

# Check for membership (this is very fast in sets)
print(3 in my_set) # True
```

### Boolean Type: `bool`

Represents one of two values: `True` or `False`. Booleans are often the result of comparisons.

```python
is_active = True
has_permission = False
is_greater = 10 > 5 # True

if is_active and is_greater:
    print("User is active and the number is greater.")
```

### None Type: `NoneType`

Has only one value, `None`. It is used to signify the absence of a value.

```python
# A variable that currently has no value
result = None
```
