# Error Handling in Python

Errors are bound to happen in your code. Python uses exceptions to handle errors and other exceptional events.

## 1. Common Exceptions

- `SyntaxError`: Caused by a parsing error (e.g., a missing parenthesis). This error cannot be handled.
- `IndentationError`: Raised when there is incorrect indentation.
- `NameError`: Occurs when a variable or function name is not found.
- `TypeError`: Raised when an operation or function is applied to an object of an inappropriate type.
- `ValueError`: Raised when a function receives an argument of the correct type but an inappropriate value.
- `IndexError`: Occurs if you try to access an element in a list or tuple outside its index range.
- `KeyError`: Occurs if you try to access a key in a dictionary that does not exist.
- `ZeroDivisionError`: Raised when the second argument of a division or modulo operation is zero.

## 2. Handling Exceptions

We use `try`, `except`, `else`, and `finally` blocks to handle exceptions.

### `try` and `except`

The `try` block lets you test a block of code for errors. The `except` block lets you handle the error.

```python
try:
    # This code might cause an error
    result = 10 / 0
except ZeroDivisionError:
    # This code executes if a ZeroDivisionError occurs
    print("You can't divide by zero!")
```

You can handle multiple exceptions by adding more `except` blocks.

```python
try:
    value = int(input("Enter a number: "))
    result = 20 / value
except ValueError:
    print("Invalid input. Please enter a number.")
except ZeroDivisionError:
    print("You cannot divide by zero.")
```

You can also handle multiple exceptions with a single `except` block by grouping them in a tuple.

```python
try:
    # ... some code
except (ValueError, ZeroDivisionError):
    print("An error related to value or division occurred.")
```

### The `else` Block
The `else` block lets you execute code when there is no error.

```python
try:
    x = int(input("Enter a number: "))
except ValueError:
    print("That was not a valid number.")
else:
    print(f"You entered the number {x}.")
```

### The `finally` Block
The `finally` block lets you execute code, regardless of the result of the `try` and `except` blocks. This is often used for cleanup actions, like closing files.

```python
try:
    f = open("my_file.txt", "r")
    # ... do something with the file
except FileNotFoundError:
    print("File not found.")
finally:
    # This block will always execute, ensuring the file is closed.
    if 'f' in locals() and not f.closed:
        f.close()
        print("File closed.")
```

## 3. Raising Exceptions

You can choose to throw an exception if a condition occurs using the `raise` keyword.

```python
x = -1

if x < 0:
    raise ValueError("Number cannot be negative")
```
This is useful for enforcing certain rules or constraints in your code.
