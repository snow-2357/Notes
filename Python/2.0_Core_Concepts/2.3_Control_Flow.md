# Control Flow in Python

Control flow is the order in which a program's code executes. In Python, this is managed with conditional statements, loops, and other control structures.

---

## 1. Conditional Statements

Conditional statements allow you to execute blocks of code based on whether a condition is true or false.

### `if`, `elif`, and `else`
- `if`: Executes a block of code if its condition is true.
- `elif` (else if): Checks for another condition if the previous `if` or `elif` conditions were false.
- `else`: Executes if none of the preceding `if` or `elif` conditions are true.

```python
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"

print(f"Your grade is {grade}") # Output: Your grade is B
```

### The `match` Statement (Structural Pattern Matching)
Introduced in Python 3.10, the `match` statement is a more powerful and readable alternative to complex `if...elif...else` chains, especially when comparing a variable against multiple possible values (patterns).

```python
status_code = 404

match status_code:
    case 200:
        print("OK")
    case 404:
        print("Not Found")
    case 500:
        print("Internal Server Error")
    case _:  # The underscore `_` is a wildcard, acting like a default 'else'
        print("Unknown status")

# Output: Not Found
```
It can also be used for more complex matching with data structures:
```python
point = (0, 10)

match point:
    case (0, 0):
        print("Origin")
    case (0, y):
        print(f"On the Y-axis at y={y}")
    case (x, 0):
        print(f"On the X-axis at x={x}")
    case (x, y):
        print(f"Point at x={x}, y={y}")
```

## 2. Loops

Loops are used to execute a block of code repeatedly.

### `for` Loop
A `for` loop is used for iterating over a sequence (like a list, tuple, string, or range).

```python
# Looping through a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# Using the range() function
for i in range(3):  # It will loop from 0 to 2
    print(f"Loop number {i}")
```

### `while` Loop
A `while` loop executes a set of statements as long as its condition remains true.

```python
count = 0
while count < 3:
    print(f"Count is {count}")
    count += 1
```

### Nested Loops
You can use one or more loops inside another loop. This is useful for working with multi-dimensional data structures.

```python
# Example: Printing a 2D grid's coordinates
for x in range(2):  # Outer loop
    for y in range(3):  # Inner loop
        print(f"({x}, {y})")
# Output:
# (0, 0)
# (0, 1)
# (0, 2)
# (1, 0)
# (1, 1)
# (1, 2)
```

## 3. Loop Control Statements

These statements change a loop's execution from its normal sequence.

### `break`
The `break` statement immediately terminates the innermost loop it's in.

```python
for i in range(10):
    if i == 5:
        break  # The loop will stop when i is 5
    print(i)
# Output: 0, 1, 2, 3, 4
```

### `continue`
The `continue` statement skips the rest of the current iteration and proceeds to the next one.

```python
for i in range(5):
    if i == 2:
        continue  # Skips printing the number 2
    print(i)
# Output: 0, 1, 3, 4
```

### The `else` Clause in Loops
A unique feature in Python is the `else` block for loops. The `else` block executes **only if the loop completes its entire iteration without being terminated by a `break` statement**.

```python
# Example with 'for' loop
for i in range(5):
    print(i)
else:
    print("The loop finished without a break.")

# Example where 'else' does NOT run
for i in range(5):
    if i == 3:
        break
    print(i)
else:
    print("This will not be printed.")
```

### `pass` Statement
The `pass` statement is a null operation; nothing happens when it executes. It is used as a placeholder where code will eventually go, to avoid syntax errors.

```python
def my_future_function():
    pass  # I'll implement this later

if 10 > 5:
    pass # Placeholder for a code block
```

## 4. List Comprehensions: A Concise Alternative

List comprehensions provide a short and readable way to create lists, often as a single-line replacement for a `for` loop.

**Standard `for` loop:**
```python
squares = []
for i in range(5):
    squares.append(i * i)
# squares is now [0, 1, 4, 9, 16]
```

**Equivalent List Comprehension:**
```python
squares = [i * i for i in range(5)]
# squares is now [0, 1, 4, 9, 16]
```

You can also include conditions:
```python
even_squares = [i * i for i in range(10) if i % 2 == 0]
# even_squares is now [0, 4, 16, 36, 64]
```

## 5. Practical Exercises

1.  **FizzBuzz**:
    - Write a `for` loop that iterates from 1 to 100.
    - For multiples of three, print "Fizz" instead of the number.
    - For multiples of five, print "Buzz".
    - For numbers which are multiples of both three and five, print "FizzBuzz".
    - Otherwise, print the number.

2.  **Number Guessing Game**:
    - Write a `while` loop that gives a user 3 attempts to guess a secret number (e.g., 7).
    - If they guess correctly, print "You win!" and `break` the loop.
    - If they run out of attempts, use an `else` block on the loop to print "You lose!".

3.  **Command Processor**:
    - Use a `match` statement to simulate processing user commands.
    - Create a variable `command` and test it with values like "start", "stop", and "restart".
    - Include a case for each command and a wildcard case for unknown commands.

4.  **Power of Two**:
    - Use a list comprehension to create a list containing the first 10 powers of 2 (2^0, 2^1, 2^2, ...).
