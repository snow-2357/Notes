# Python Operators

Operators are special symbols in Python that carry out arithmetic, logical, and other types of computation. Understanding them is fundamental to programming.

---

## 1. Arithmetic Operators

Used to perform mathematical operations.

| Operator | Description    | Example      |
| :------- | :------------- | :----------- |
| `+`      | Addition       | `x + y`      |
| `-`      | Subtraction    | `x - y`      |
| `*`      | Multiplication | `x * y`      |
| `/`      | Division       | `x / y`      |
| `%`      | Modulus        | `x % y`      |
| `**`     | Exponentiation | `x ** y`     |
| `//`     | Floor Division | `x // y`     |

```python
a = 10
b = 3

print(f"{a} / {b} = {a / b}")   # 3.333... (float division)
print(f"{a} // {b} = {a // b}")  # 3 (discards the fractional part)
print(f"{a} % {b} = {a % b}")   # 1 (remainder of the division)
print(f"{a} ** {b} = {a ** b}")  # 1000 (10 to the power of 3)
```

## 2. Assignment Operators

Used to assign values to variables. The standard assignment operator is `=`. Python also provides augmented assignment operators for convenience.

| Operator | Example  | Equivalent To |
| :------- | :------- | :------------ |
| `=`      | `x = 5`  | `x = 5`       |
| `+=`     | `x += 3` | `x = x + 3`   |
| `-=`     | `x -= 3` | `x = x - 3`   |
| `*=`     | `x *= 3` | `x = x * 3`   |
| `/=`     | `x /= 3` | `x = x / 3`   |
| `//=`    | `x //= 3`| `x = x // 3`  |
| `**=`    | `x **= 3`| `x = x ** 3`  |

```python
count = 5
count += 1  # Increment count by 1
print(f"Count is now: {count}") # "Count is now: 6"
```

---

## 3. Comparison (Relational) Operators

Used to compare two values, resulting in a `True` or `False` boolean value.

| Operator | Description                | Example     |
| :------- | :------------------------- | :---------- |
| `==`     | Equal                      | `x == y`    |
| `!=`     | Not equal                  | `x != y`    |
| `>`      | Greater than               | `x > y`     |
| `<`      | Less than                  | `x < y`     |
| `>=`     | Greater than or equal to   | `x >= y`    |
| `<=`     | Less than or equal to      | `x <= y`    |

```python
x = 5
y = 10
print(f"Is x equal to y? {x == y}")       # False
print(f"Is x less than y? {x < y}")        # True
print(f"Is y greater than or equal to 10? {y >= 10}") # True
```

## 4. Logical Operators

Used to combine conditional statements.

| Operator | Description                                   | Example           |
| :------- | :-------------------------------------------- | :---------------- |
| `and`    | Returns `True` if both statements are true    | `x < 5 and x < 10` |
| `or`     | Returns `True` if one of the statements is true | `x < 5 or x < 4` |
| `not`    | Reverse the result, returns `False` if the result is true | `not(x < 5)`      |

### Short-Circuit Evaluation

Logical operators in Python use "short-circuit" evaluation. This means they only evaluate the second operand if necessary.

- For `a and b`: If `a` is `False`, the expression is immediately `False`, and `b` is never evaluated.
- For `a or b`: If `a` is `True`, the expression is immediately `True`, and `b` is never evaluated.

This is useful for performance and for avoiding errors:
```python
x = 5
# The second part (x / 0) would cause a ZeroDivisionError,
# but it's never evaluated because the first part is False.
result = (x > 10) and (x / 0 == 1) 
print(result) # False
```

## 5. Identity and Membership Operators

### Identity Operators (`is`, `is not`)
Used to compare the memory locations of two objects. This is different from `==`, which compares the values.

| Operator | Description                                       | Example       |
| :------- | :------------------------------------------------ | :------------ |
| `is`     | Returns `True` if both variables are the same object | `x is y`      |
| `is not` | Returns `True` if they are not the same object | `x is not y`  |

```python
list1 = [1, 2]
list2 = [1, 2]
list3 = list1

print(list1 == list2) # True (values are the same)
print(list1 is list2) # False (they are two different objects in memory)
print(list1 is list3) # True (they refer to the exact same object)
```

### Membership Operators (`in`, `not in`)
Used to test if a value is present in a sequence (like a list, tuple, or string).

| Operator | Description                                        | Example      |
| :------- | :------------------------------------------------- | :----------- |
| `in`     | Returns `True` if a value is present in the object | `x in y`     |
| `not in` | Returns `True` if a value is not present           | `x not in y` |

```python
my_fruits = ["apple", "banana"]
print("banana" in my_fruits)       # True
print("orange" not in my_fruits) # True
```

## 6. Bitwise Operators

These operators are used to perform bit-level operations on integers. They are less common in day-to-day high-level programming but are powerful for specific tasks like data compression, encryption, or low-level device control.

| Operator | Description      | Example     |
| :------- | :--------------- | :---------- |
| `&`      | Bitwise AND      | `x & y`     |
| `|`      | Bitwise OR       | `x | y`     |
| `^`      | Bitwise XOR      | `x ^ y`     |
| `~`      | Bitwise NOT      | `~x`        |
| `<<`     | Left Shift       | `x << 2`    |
| `>>`     | Right Shift      | `x >> 2`    |

```python
# Example:
# a = 5  (in binary 0101)
# b = 3  (in binary 0011)

a = 5
b = 3

print(a & b)  # 1 (0001)
print(a | b)  # 7 (0111)
print(a ^ b)  # 6 (0110)
print(~a)     # -6 (Inverts all bits)
print(a << 1) # 10 (Shifts bits to the left, equivalent to a * 2)
print(a >> 1) # 2  (Shifts bits to the right, equivalent to a // 2)
```

## 7. Operator Precedence

Python evaluates operators in a specific order. The following table lists the precedence from highest to lowest.

| Precedence | Operator                             | Description                    |
| :---:      | :----------------------------------- | :----------------------------- |
| 1          | `()`                                 | Parentheses                    |
| 2          | `**`                                 | Exponentiation                 |
| 3          | `+x`, `-x`, `~x`                     | Unary Plus, Unary Minus, Bitwise NOT |
| 4          | `*`, `/`, `//`, `%`                  | Multiplication, Division, etc. |
| 5          | `+`, `-`                             | Addition, Subtraction          |
| 6          | `<<`, `>>`                           | Bitwise Shifts                 |
| 7          | `&`                                  | Bitwise AND                    |
| 8          | `^`                                  | Bitwise XOR                    |
| 9          | `|`                                  | Bitwise OR                     |
| 10         | `==`, `!=`, `>`, `>=`, `<`, `<=`     | Comparisons                    |
| 11         | `is`, `is not`, `in`, `not in`     | Identity, Membership           |
| 12         | `not`                                | Logical NOT                    |
| 13         | `and`                                | Logical AND                    |
| 14         | `or`                                 | Logical OR                     |

When in doubt, use parentheses `()` to make the order of evaluation explicit and improve readability.

```python
# Without parentheses, multiplication is done first
result1 = 10 + 2 * 3   # 16

# With parentheses, addition is done first
result2 = (10 + 2) * 3 # 36
```
