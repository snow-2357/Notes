# Python Operators

Operators are special symbols in Python that carry out arithmetic or logical computation.

## 1. Arithmetic Operators

Used to perform mathematical operations.

| Operator | Description    | Example      |
| :------- | :------------- | :----------- |
| `+`      | Addition       | `x + y`      |
| `-`      | Subtraction    | `x - y`      |
| `*`      | Multiplication | `x * y`      |
| `/`      | Division       | `x / y`      |
| `%`      | Modulus        | `x % y`      |
| `**`     | Exponentiation | `x ** y`     |
| `//`     | Floor Division | `x // y`     |

```python
a = 10
b = 3

print(a / b)   # 3.333...
print(a // b)  # 3 (division that results into whole number adjusted to the left in the number line)
print(a % b)   # 1 (remainder)
print(a ** b)  # 1000 (10 to the power of 3)
```

## 2. Comparison (Relational) Operators

Used to compare two values.

| Operator | Description                | Example     |
| :------- | :------------------------- | :---------- |
| `==`     | Equal                      | `x == y`    |
| `!=`     | Not equal                  | `x != y`    |
| `>`      | Greater than               | `x > y`     |
| `<`      | Less than                  | `x < y`     |
| `>=`     | Greater than or equal to   | `x >= y`    |
| `<=`     | Less than or equal to      | `x <= y`    |

```python
x = 5
y = 10
print(x == y)  # False
print(x < y)   # True
```

## 3. Logical Operators

Used to combine conditional statements.

| Operator | Description                                   | Example           |
| :------- | :-------------------------------------------- | :---------------- |
| `and`    | Returns `True` if both statements are true    | `x < 5 and x < 10` |
| `or`     | Returns `True` if one of the statements is true | `x < 5 or x < 4` |
| `not`    | Reverse the result                            | `not(x < 5)`      |

## 4. Assignment Operators

Used to assign values to variables.

| Operator | Example  | Same As      |
| :------- | :------- | :----------- |
| `=`      | `x = 5`  | `x = 5`      |
| `+=`     | `x += 3` | `x = x + 3`  |
| `-=`     | `x -= 3` | `x = x - 3`  |
| `*=`     | `x *= 3` | `x = x * 3`  |
| `/=`     | `x /= 3` | `x = x / 3`  |
| `**=`    | `x **= 3`| `x = x ** 3` |

## 5. Identity and Membership Operators

### Identity Operators
Used to compare the objects, not if they are equal, but if they are actually the same object, with the same memory location.

| Operator | Description                                       | Example       |
| :------- | :------------------------------------------------ | :------------ |
| `is`     | Returns `True` if both variables are the same object | `x is y`      |
| `is not` | Returns `True` if both variables are not the same object | `x is not y`  |

```python
list1 = []
list2 = []
list3 = list1

print(list1 is list2) # False (they are two different empty list objects)
print(list1 is list3) # True (they refer to the exact same object)
```

### Membership Operators
Used to test if a sequence is presented in an object.

| Operator | Description                                                            | Example      |
| :------- | :--------------------------------------------------------------------- | :----------- |
| `in`     | Returns `True` if a sequence with the specified value is present in the object | `x in y`     |
| `not in` | Returns `True` if a sequence with the specified value is not present in the object | `x not in y` |

```python
my_fruits = ["apple", "banana"]
print("banana" in my_fruits) # True
```
