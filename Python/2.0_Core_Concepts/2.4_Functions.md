# Functions in Python

A function is a block of organized, reusable code that is used to perform a single, related action.

## 1. Defining a Function

You define a function with the `def` keyword.

```python
# A simple function that greets the user
def greet():
    print("Hello, World!")

# Calling the function
greet()
```

## 2. Parameters and Arguments

Information can be passed into functions as arguments. Arguments are specified after the function name, inside the parentheses.

- **Parameter**: The variable listed inside the parentheses in the function definition.
- **Argument**: The value that is sent to the function when it is called.

```python
def greet_user(name): # 'name' is a parameter
    print(f"Hello, {name}!")

greet_user("Alice") # "Alice" is an argument
```

### Default Parameter Value

You can define a default value for a parameter. If you call the a function without an argument, it uses the default value.

```python
def greet(name="Guest"):
    print(f"Hello, {name}!")

greet("Bob") # Output: Hello, Bob!
greet()      # Output: Hello, Guest!
```

## 3. Return Values

Functions can return a value to the caller using the `return` statement.

```python
def add(x, y):
    return x + y

result = add(5, 3)
print(result) # Output: 8
```
A function can return multiple values. They are returned as a tuple.

```python
def get_point():
    return 10, 20

x, y = get_point()
print(f"x: {x}, y: {y}") # Output: x: 10, y: 20
```

## 4. Arbitrary Arguments: `*args` and `**kwargs`

### `*args`
If you do not know how many arguments will be passed into your function, add a `*` before the parameter name. The function will receive a **tuple** of arguments.

```python
def sum_all(*numbers):
    total = 0
    for num in numbers:
        total += num
    return total

print(sum_all(1, 2, 3))       # Output: 6
print(sum_all(10, 20, 30, 40)) # Output: 100
```

### `**kwargs`
If you do not know how many keyword arguments will be passed into your function, add two asterisks `**` before the parameter name. The function will receive a **dictionary** of arguments.

```python
def display_info(**person):
    for key, value in person.items():
        print(f"{key}: {value}")

display_info(name="Alice", age=30)
# Output:
# name: Alice
# age: 30
```

## 5. Lambda Functions

A lambda function is a small anonymous function. It can take any number of arguments, but can only have one expression.

`lambda arguments : expression`

```python
# A lambda function that adds 10 to the number passed in
x = lambda a : a + 10
print(x(5)) # Output: 15

# A lambda function that multiplies two arguments
multiply = lambda a, b : a * b
print(multiply(5, 6)) # Output: 30
```
Lambda functions are often used as anonymous functions inside other functions.

```python
def my_func(n):
    return lambda a : a * n

doubler = my_func(2)
tripler = my_func(3)

print(doubler(11)) # Output: 22
print(tripler(11)) # Output: 33
```
