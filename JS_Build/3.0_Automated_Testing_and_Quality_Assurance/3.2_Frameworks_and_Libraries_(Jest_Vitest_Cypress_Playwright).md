# 3.2 Frameworks and Libraries (Jest, Vitest, Cypress, Playwright)

This note provides an overview of the most popular tools in the JavaScript testing ecosystem.

## Unit/Integration Test Runners

These tools provide a framework for running, structuring, and asserting the results of your tests.

### Jest
- The long-time king of JavaScript testing, created by Facebook.
- **Features:** All-in-one. Includes a test runner, assertion library (`expect`), and mocking capabilities. Supports snapshot testing.
- **Pros:** Mature, feature-rich, and widely used.
- **Cons:** Can be slower than newer alternatives. Configuration with modern tools (like Vite) can sometimes be tricky.

### Vitest
- A modern test runner designed to work seamlessly with Vite.
- **Features:** Jest-compatible API (so switching from Jest is easy). Extremely fast due to its integration with Vite. Supports running tests in a real browser context.
- **Pros:** Blazing fast. First-class TypeScript/JSX support. Great developer experience.
- **Cons:** Newer than Jest, so the ecosystem is slightly smaller.

## Component Testing

Tools specifically designed to "mount" a component in isolation and interact with it.

### React Testing Library (RTL)
- The de-facto standard for testing React components. It can be used with Jest or Vitest.
- **Philosophy:** "Test your software in the same way that your users use it." It encourages you to find elements by accessible attributes (like text content or labels) rather than implementation details (like CSS classes or component state).
- **Not a test runner:** It's a library that provides utilities for rendering components and simulating user events.

## End-to-End (E2E) Testing Frameworks

These tools automate real browsers to test your application from end to end.

### Cypress
- An all-in-one E2E testing framework that was revolutionary for its developer experience.
- **Features:** A time-traveling GUI that shows you exactly what happened at each step of your test. Automatic waiting for elements to appear.
- **Pros:** Excellent for debugging. Easy to get started with.
- **Cons:** Tests are written in a way that can lead to "the pyramid of doom" for complex scenarios. Runs in the same loop as your app, which can be limiting.

### Playwright
- A newer E2E framework from Microsoft, created by the original Puppeteer team.
- **Features:** Can automate Chromium (Chrome, Edge), Firefox, and WebKit (Safari). Supports parallel test execution. Has a "code-gen" tool that can record your actions in the browser and generate a test script.
- **Pros:** Extremely fast and powerful. Cross-browser support is a major advantage.
- **Cons:** Can have a slightly steeper learning curve than Cypress. The tooling is less "visual" than Cypress's GUI.
