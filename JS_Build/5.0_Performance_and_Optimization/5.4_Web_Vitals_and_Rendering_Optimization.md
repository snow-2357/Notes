# 5.4 Web Vitals and Rendering Optimization

This note focuses on techniques to improve the Core Web Vitals and general rendering performance, particularly in the context of a framework like React.

## Optimizing Largest Contentful Paint (LCP)

LCP measures loading performance. To improve it, you need to make sure the largest element in the viewport renders as quickly as possible.

- **Prioritize the LCP element:** Ensure that the resource for your LCP element (e.g., a hero image or a block of text) is discovered and loaded early.
- **Preload critical assets:** Use `<link rel="preload">` to tell the browser to start downloading a critical resource sooner.
    ```html
    <link rel="preload" href="/path/to/hero-image.webp" as="image">
    ```
- **Optimize images:** Serve properly sized images, use modern formats (like WebP or AVIF), and compress them efficiently.
- **Reduce Server Response Time (TTFB):** Use a CDN, cache responses on the server, and optimize your backend queries.
- **Eliminate Render-Blocking Resources:** Move non-critical scripts to the end of the `<body>` or use `async` or `defer` attributes. Load non-critical CSS asynchronously.

## Optimizing Cumulative Layout Shift (CLS)

CLS measures visual stability. To improve it, you need to avoid unexpected shifts in the page layout.

- **Always include size attributes on images and videos:**
    ```html
    <img src="image.jpg" width="640" height="360" alt="...">
    ```
    This allows the browser to reserve the correct amount of space for the image before it loads.
- **Reserve space for ads and embeds:** If you know a component will be a certain size, reserve that space with a `min-height`.
- **Avoid inserting content above existing content:** Unless it's in response to a user interaction.

## Optimizing Interactivity (FID / INP)

FID and INP measure responsiveness. To improve them, you need to keep the main thread free to respond to user input.

- **Break up Long Tasks:** If you have a long-running JavaScript function, it can block the main thread. Break it up into smaller, asynchronous tasks using `setTimeout` or `requestIdleCallback`.
- **Avoid Large Re-renders in React:**
    - Use `React.memo`, `useCallback`, and `useMemo` to prevent unnecessary re-renders of components.
    - **Virtualize long lists:** Use libraries like `react-window` or `react-virtual` to only render the items in a long list that are currently visible in the viewport.
- **Use Web Workers:** For truly heavy, non-UI computation, move the work off the main thread entirely by using a Web Worker.
- **React 18 Concurrent Features:**
    - **`startTransition`:** Allows you to mark a state update as a "transition," which tells React that it's okay to render it in the background without blocking the main thread. This is ideal for updates that might cause a noticeable lag, like filtering a large list.
    ```javascript
    startTransition(() => {
      setFilterTerm(input);
    });
    ```
