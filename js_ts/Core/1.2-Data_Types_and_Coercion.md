# 1.2 Data Types and Type Coercion

JavaScript is a **dynamically typed** language. This means you don't have to specify the type of a variable when you declare it. The type is determined at runtime.

## JavaScript Data Types

There are two main categories of data types in JavaScript: **Primitive Types** and **Object Types**.

### Primitive Types
A primitive is an immutable piece of data—it cannot be changed. There are 7 primitive types:

1.  **`string`**: A sequence of characters. e.g., `"hello"`.
2.  **`number`**: Numeric values, including integers and floats. e.g., `42`, `3.14`. Also includes special values like `Infinity`, `-Infinity`, and `NaN` (Not-a-Number).
3.  **`boolean`**: Represents a logical entity and can have two values: `true` and `false`.
4.  **`null`**: Represents the intentional absence of any object value. It is treated as a "falsy" value.
5.  **`undefined`**: A variable that has been declared but has not yet been assigned a value.
6.  **`symbol`** (ES6): A unique and immutable value that may be used as the key of an Object property.
7.  **`bigint`** (ES2020): Represents whole numbers larger than the `number` type can safely represent.

```javascript
let myString = "Gemini";
let myNumber = 10;
let isLearning = true;
let noValue = null;
let notAssigned; // undefined
```

### Object Types
An object is a collection of properties, and a property is an association between a name (or key) and a value. An object is a **mutable** data type.

-   **`object`**: The basic object type. e.g., `{ key: 'value' }`.
-   **`array`**: A special type of object used for ordered collections. e.g., `[1, 2, 3]`.
-   **`function`**: A special type of object that can be called or invoked.

## The `typeof` Operator and its Quirks

The `typeof` operator returns a string indicating the type of the unevaluated operand.

```javascript
typeof "hello";   // "string"
typeof 100;       // "number"
typeof true;      // "boolean"
typeof undefined; // "undefined"
typeof Symbol();  // "symbol"
typeof { a: 1 };  // "object"
typeof [1, 2];    // "object" (Arrays are objects!)
typeof function(){}; // "function"
```

**Quirk**: `typeof null` returns `"object"`. This is a long-standing bug in JavaScript that, for legacy reasons, will likely never be fixed.

```javascript
console.log(typeof null); // "object"
```

## Type Coercion: When JavaScript Changes Types for You

Type coercion is the automatic or implicit conversion of values from one data type to another. This happens frequently in JavaScript, especially with operators.

### The Double Equals `==` (Loose Equality)
The `==` operator compares two values for equality **after** performing type coercion if necessary. This can lead to unexpected results.

**Rules and Examples:**
- If one operand is a string and the other is a number, the string is converted to a number.
- `null` is only equal to `undefined`.
- `NaN` is not equal to anything, including itself.

```javascript
console.log(1 == '1');       // true (string '1' is coerced to number 1)
console.log(true == 1);        // true (boolean true is coerced to number 1)
console.log(false == 0);       // true (boolean false is coerced to number 0)
console.log(null == undefined); // true

console.log(0 == '');          // true (empty string is coerced to 0)
console.log('' == false);      // true
```

### The Triple Equals `===` (Strict Equality)
The `===` operator compares two values for equality **without** performing type coercion. It checks both the value and the type.

**It is highly recommended to always use `===` to avoid bugs from unexpected type coercion.**

```javascript
console.log(1 === '1');       // false (number vs. string)
console.log(true === 1);        // false (boolean vs. number)
console.log(null === undefined); // false
```

### Truthy and Falsy Values
In a boolean context (like an `if` statement), JavaScript coerces values to `true` or `false`.

**Falsy Values**: There are only 8 falsy values in JavaScript. Everything else is truthy.
1.  `false`
2.  `0`
3.  `-0`
4.  `0n` (BigInt zero)
5.  `""` (empty string)
6.  `null`
7.  `undefined`
8.  `NaN`

**Example:**
```javascript
if ("hello") {
  // This code runs because "hello" is truthy
}

if (0) {
  // This code does NOT run because 0 is falsy
}
```
