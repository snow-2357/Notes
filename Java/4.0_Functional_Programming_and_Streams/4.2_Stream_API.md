# Stream API in Java

The Stream API, introduced in Java 8, is used to process collections of objects. A stream is a sequence of objects that supports various methods which can be pipelined to produce the desired result.

---

## 1. What is a Stream?

A **Stream** is not a data structure; it's a sequence of data elements from a source (like a `Collection`, `Array`, or I/O channel). Streams are designed to be declarative, meaning you describe *what* to do, not *how* to do it.

### Key Features:
- **No Storage**: A stream does not store data. It carries data from a source through a pipeline of computational steps.
- **Functional in Nature**: Operations on a stream produce a result but do not modify its source.
- **Laziness-oriented**: Many stream operations (like `filter`, `map`) are lazy; they are not executed until a terminal operation is invoked.
- **Possibly Unbounded**: While collections have a finite size, streams do not need to.
- **Consumable**: The elements of a stream are only visited once during the life of a stream.

---

## 2. Stream Pipeline

A stream pipeline consists of:
1.  **A Source**: (e.g., `Collection`, `Array`, `Files.lines()`).
2.  **Zero or more Intermediate Operations**: (e.g., `filter`, `map`, `sorted`). These transform a stream into another stream.
3.  **A Terminal Operation**: (e.g., `forEach`, `collect`, `reduce`). This produces a result or a side-effect and marks the end of the stream.

```java
List<String> names = Arrays.asList("Reflection", "Collection", "Stream", "Structure");

List<String> result = names.stream()               // 1. Source
    .filter(s -> s.startsWith("S"))                // 2. Intermediate Operation
    .map(String::toUpperCase)                      // 3. Intermediate Operation
    .collect(Collectors.toList());                 // 4. Terminal Operation

System.out.println(result); // Output: [STREAM, STRUCTURE]
```

---

## 3. Common Intermediate Operations

These operations return a new stream and are always lazy.

- **`filter(Predicate)`**: Filters elements based on a condition.
- **`map(Function)`**: Transforms each element into another object.
- **`flatMap(Function)`**: Flattens a stream of streams into a single stream.
- **`distinct()`**: Removes duplicate elements (based on `equals()`).
- **`sorted()`**: Sorts the elements naturally or with a `Comparator`.
- **`limit(n)`**: Truncates the stream to contain no more than `n` elements.
- **`skip(n)`**: Discards the first `n` elements of the stream.

```java
// Example of flatMap
List<List<String>> complexList = Arrays.asList(
    Arrays.asList("a", "b"),
    Arrays.asList("c", "d")
);

List<String> flatList = complexList.stream()
    .flatMap(Collection::stream)
    .collect(Collectors.toList()); // [a, b, c, d]
```

---

## 4. Common Terminal Operations

These operations trigger the processing of the stream and return a non-stream result.

- **`forEach(Consumer)`**: Performs an action for each element.
- **`collect(Collector)`**: Transforms the stream into a different form (like a `List`, `Set`, or `Map`).
- **`reduce(BinaryOperator)`**: Combines stream elements into a single result (e.g., sum, max).
- **`count()`**: Returns the number of elements in the stream.
- **`anyMatch(Predicate)`**, **`allMatch`**, **`noneMatch`**: Returns `boolean` based on conditions.
- **`findFirst()`**, **`findAny()`**: Returns an `Optional` containing an element from the stream.

```java
// Example of reduce
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
int sum = numbers.stream()
    .reduce(0, (a, b) -> a + b); // Output: 15
```

---

## 5. Collectors

The `Collectors` class provides many static methods for common terminal operations.

- `Collectors.toList()`
- `Collectors.toSet()`
- `Collectors.joining(", ")` (Concatenates strings)
- `Collectors.groupingBy(Function)` (Groups elements by a key)
- `Collectors.partitioningBy(Predicate)` (Partitions elements into two groups: true and false)

```java
// Grouping by string length
Map<Integer, List<String>> groups = names.stream()
    .collect(Collectors.groupingBy(String::length));
```

---

## 6. Parallel Streams

Streams can be executed in parallel to leverage multi-core processors. You can turn any stream into a parallel stream by calling `.parallelStream()` or `.parallel()`.

```java
long count = list.parallelStream()
    .filter(x -> x > 100)
    .count();
```

**Caution**: Use parallel streams only for large datasets and stateless, non-interfering, and associative operations. For small datasets or operations with high overhead, sequential streams are often faster.
