# Lambda Expressions and Functional Interfaces in Java

Lambda expressions, introduced in Java 8, are a major step towards functional programming in Java. They provide a clear and concise way to represent one method interface using an expression.

---

## 1. Functional Interfaces

A **Functional Interface** is an interface that contains exactly **one abstract method**. They can have any number of default or static methods.

### The `@FunctionalInterface` Annotation
While not strictly required, this annotation helps the compiler ensure the interface stays functional. If you add a second abstract method, the compiler will throw an error.

```java
@FunctionalInterface
interface MathOperation {
    int operation(int a, int b);
    
    // Default methods are allowed
    default void log(int a, int b, int result) {
        System.out.println("Result of " + a + " and " + b + " is " + result);
    }
}
```

### Built-in Functional Interfaces (`java.util.function`)
Java provides several standard functional interfaces for common tasks:
- `Predicate<T>`: Takes one argument, returns `boolean`. (Method: `test`)
- `Function<T, R>`: Takes one argument of type `T`, returns type `R`. (Method: `apply`)
- `Consumer<T>`: Takes one argument, returns `void`. (Method: `accept`)
- `Supplier<T>`: Takes no arguments, returns type `T`. (Method: `get`)
- `BiFunction<T, U, R>`: Takes two arguments, returns type `R`. (Method: `apply`)

---

## 2. Lambda Expressions

Lambda expressions are essentially anonymous methods. They don't have a name, and they don't belong to any class.

### Syntax
`(parameters) -> expression`
or
`(parameters) -> { statements; }`

```java
// Traditional Anonymous Class
MathOperation addition = new MathOperation() {
    @Override
    public int operation(int a, int b) {
        return a + b;
    }
};

// Lambda Expression equivalent
MathOperation additionLambda = (a, b) -> a + b;

System.out.println(additionLambda.operation(10, 5)); // Output: 15
```

### Characteristics
- **Optional Type Declaration**: No need to declare the type of a parameter. The compiler can inference the type from the value of the parameter.
- **Optional Parenthesis around Parameter**: No need to declare a single parameter in parenthesis. For multiple parameters, parentheses are required.
- **Optional Curly Braces**: No need to use curly braces in expression body if the body contains a single statement.
- **Optional Return Keyword**: The compiler automatically returns the value if the body has a single expression to return the value.

---

## 3. Method References

Method references are a shorthand notation of a lambda expression to call a method. They use the `::` operator.

Types of method references:
1. **Static Method**: `ClassName::staticMethodName`
2. **Instance Method of a particular object**: `obj::instanceMethodName`
3. **Instance Method of an arbitrary object of a particular type**: `ClassName::methodName`
4. **Constructor**: `ClassName::new`

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");

// Lambda expression
names.forEach(name -> System.out.println(name));

// Method reference equivalent
names.forEach(System.out::println);
```

---

## 4. Variable Capture (Closure)

Lambdas can use variables defined in the outer scope, but there's a restriction: the variable must be **effectively final**. This means its value cannot be changed after it's assigned.

```java
int factor = 2;
MathOperation multiply = (a, b) -> (a + b) * factor; 

// factor = 3; // This would cause a compilation error in the lambda above
```

## 5. Practical Examples

### Using Predicate to filter a list
```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5, 6);
Predicate<Integer> isEven = n -> n % 2 == 0;

numbers.stream()
       .filter(isEven)
       .forEach(System.out::println); // Prints 2, 4, 6
```

### Using Function to transform data
```java
Function<String, Integer> stringLength = s -> s.length();
System.out.println(stringLength.apply("Hello Lambda")); // Output: 12
```
