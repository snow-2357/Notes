# Java Collections Framework

The Java Collections Framework (JCF) provides a set of interfaces and classes to store and manipulate groups of data efficiently.

---

## 1. Hierarchy of Collections

The JCF is divided into two main parts: the `Collection` interface and the `Map` interface.

### The `Collection` Interface
- **`List`**: Ordered collection that allows duplicates.
  - `ArrayList`: Resizable array. Fast for random access.
  - `LinkedList`: Doubly-linked list. Fast for insertions/deletions.
- **`Set`**: Unordered collection that does not allow duplicates.
  - `HashSet`: Uses hashing. No guaranteed order.
  - `TreeSet`: Sorted order.
  - `LinkedHashSet`: Maintains insertion order.
- **`Queue`**: Designed for holding elements prior to processing (FIFO).
  - `PriorityQueue`: Elements ordered by priority.

### The `Map` Interface
Maps store data in **key-value pairs**.
- `HashMap`: No guaranteed order. Allows one null key.
- `TreeMap`: Sorted by keys.
- `LinkedHashMap`: Maintains insertion order.

---

## 2. Common Operations

```java
// List Example
List<String> list = new ArrayList<>();
list.add("Java");
list.get(0); // "Java"

// Set Example
Set<Integer> set = new HashSet<>();
set.add(10);
set.add(10); // Duplicate ignored

// Map Example
Map<String, Integer> map = new HashMap<>();
map.put("Alice", 25);
System.out.println(map.get("Alice")); // 25
```

---

## 3. ArrayList vs. LinkedList

| Feature | ArrayList | LinkedList |
| :--- | :--- | :--- |
| **Data Structure** | Dynamic Array | Doubly Linked List |
| **Access** | Fast (O(1)) | Slow (O(n)) |
| **Manipulation** | Slow (due to shifting) | Fast (no shifting) |
| **Memory** | Less overhead | More overhead (pointers) |

## 4. Iterating through Collections

### Iterator
The standard way to traverse a collection while allowing safe removal.

```java
Iterator<String> it = list.iterator();
while(it.hasNext()) {
    System.out.println(it.next());
}
```

### For-Each Loop
The most common and readable way to iterate.

```java
for (String s : list) {
    System.out.println(s);
}
```

### Streams (Java 8+)
A modern, functional way to process collections.

```java
list.stream()
    .filter(s -> s.startsWith("J"))
    .forEach(System.out::println);
```

## 5. Sorting Collections

Use `Collections.sort()` for Lists or `TreeSet`/`TreeMap` for automatic sorting.

```java
List<Integer> numbers = Arrays.asList(5, 2, 8);
Collections.sort(numbers); // [2, 5, 8]
```

For custom sorting, implement the `Comparable` or `Comparator` interface.
- **`Comparable`**: Used for natural sorting (within the class itself).
- **`Comparator`**: Used for external/multiple sorting criteria.
