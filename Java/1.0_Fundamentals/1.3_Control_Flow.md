# Control Flow in Java

Control flow statements break up the flow of execution by employing decision making, looping, and branching, enabling your program to conditionally execute particular blocks of code.

---

## 1. Decision Making Statements

### If-Else Statements
The most basic control flow statement.

```java
int score = 85;

if (score >= 90) {
    System.out.println("Grade: A");
} else if (score >= 80) {
    System.out.println("Grade: B");
} else {
    System.out.println("Grade: C");
}
```

### Switch Statement
The `switch` statement allows a variable to be tested for equality against a list of values.

```java
int day = 3;
switch (day) {
    case 1 -> System.out.println("Monday");
    case 2 -> System.out.println("Tuesday");
    case 3 -> System.out.println("Wednesday");
    default -> System.out.println("Invalid day");
}
```
*Note: The arrow syntax (`->`) was introduced in Java 14 as a more concise alternative to the traditional `case: break;` syntax.*

## 2. Looping Statements

### For Loop
Used when you know exactly how many times you want to loop through a block of code.

```java
for (int i = 0; i < 5; i++) {
    System.out.println("Iteration: " + i);
}

// Enhanced for loop (for-each) - Used for arrays/collections
String[] fruits = {"Apple", "Banana", "Cherry"};
for (String fruit : fruits) {
    System.out.println(fruit);
}
```

### While Loop
Loops through a block of code as long as a specified condition is `true`.

```java
int count = 0;
while (count < 5) {
    System.out.println("Count is: " + count);
    count++;
}
```

### Do-While Loop
Similar to the `while` loop, but it will execute the code block **once** before checking if the condition is true.

```java
int i = 0;
do {
    System.out.println(i);
    i++;
} while (i < 0); // Executes once even though condition is false
```

---

## 3. Branching Statements

### Break and Continue
- **`break`**: Terminates the loop or switch statement immediately.
- **`continue`**: Skips the current iteration of a loop and moves to the next one.

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) break;    // Stop at 5
    if (i % 2 == 0) continue; // Skip even numbers
    System.out.println(i);
}
```

### Return
Used to exit from the current method, with or without a value.

```java
public int sum(int a, int b) {
    return a + b; // Returns the sum and exits the method
}
```

## 4. Practical Exercise: FizzBuzz

Write a loop that prints numbers from 1 to 15. For multiples of 3, print "Fizz" instead of the number. For multiples of 5, print "Buzz". For multiples of both 3 and 5, print "FizzBuzz".

```java
for (int i = 1; i <= 15; i++) {
    if (i % 3 == 0 && i % 5 == 0) {
        System.out.println("FizzBuzz");
    } else if (i % 3 == 0) {
        System.out.println("Fizz");
    } else if (i % 5 == 0) {
        System.out.println("Buzz");
    } else {
        System.out.println(i);
    }
}
```
