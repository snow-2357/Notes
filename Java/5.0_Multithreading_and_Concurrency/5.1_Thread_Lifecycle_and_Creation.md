# Thread Lifecycle and Creation in Java

Multithreading is a specialized form of multitasking that allows a program to execute multiple parts of its code simultaneously. In Java, each of these parts is called a **Thread**.

---

## 1. Creating Threads

In Java, there are two primary ways to create a thread:

### Option 1: Extending the `Thread` class
You create a subclass of `Thread` and override its `run()` method.

```java
class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println("Thread is running: " + Thread.currentThread().getName());
    }
}

// Starting the thread
MyThread t1 = new MyThread();
t1.start(); // This starts the new thread and calls run()
```

### Option 2: Implementing the `Runnable` interface
You implement the `Runnable` interface and its `run()` method, then pass an instance of your class to a `Thread` object. **This is generally preferred** as it leaves the class free to extend other classes.

```java
class MyRunnable implements Runnable {
    @Override
    public void run() {
        System.out.println("Runnable is running: " + Thread.currentThread().getName());
    }
}

// Starting the thread
Thread t2 = new Thread(new MyRunnable());
t2.start();
```

---

## 2. Thread Lifecycle (States)

A thread can be in one of the following states (as defined by `Thread.State` enum):

1.  **NEW**: A thread that has been created but not yet started via `start()`.
2.  **RUNNABLE**: A thread that is ready to run and waiting for CPU time from the scheduler.
3.  **BLOCKED**: A thread that is waiting to acquire a monitor lock (e.g., trying to enter a `synchronized` block).
4.  **WAITING**: A thread that is waiting indefinitely for another thread to perform a particular action (via `wait()` or `join()`).
5.  **TIMED_WAITING**: A thread that is waiting for another thread to perform an action for a specified waiting time (via `sleep(ms)` or `wait(ms)`).
6.  **TERMINATED**: A thread that has finished executing its `run()` method.

---

## 3. Important Thread Methods

- **`start()`**: Starts the thread's execution. It calls the `run()` method in a separate thread.
- **`run()`**: Contains the code that will be executed by the thread.
- **`sleep(long millis)`**: Causes the currently executing thread to sleep for the specified number of milliseconds.
- **`join()`**: Waits for the thread to die. It blocks the current thread until the thread it's called on finishes.
- **`yield()`**: A hint to the scheduler that the current thread is willing to yield its current use of the processor.
- **`interrupt()`**: Interrupts the thread's current state (often used to wake up a sleeping or waiting thread).
- **`isAlive()`**: Checks if the thread is still running.

```java
Thread t = new Thread(() -> {
    try {
        Thread.sleep(1000);
    } catch (InterruptedException e) {
        System.out.println("Interrupted!");
    }
});
t.start();
t.join(); // Main thread waits for 't' to finish
```

---

## 4. Main Thread

When a Java program starts, one thread begins running immediately: the **Main Thread**. It's important because:
- It's the thread from which other threads will be spawned.
- It's usually the last thread to finish execution because it performs various shutdown actions.

---

## 5. Daemon Threads

A **Daemon Thread** is a low-priority thread that runs in the background to perform tasks like garbage collection.

- Java continues to run as long as any **user thread** (non-daemon thread) is alive.
- If only daemon threads are left, the JVM will shut down automatically.

```java
Thread daemonThread = new Thread(() -> {
    while (true) {
        // do some background work
    }
});
daemonThread.setDaemon(true); // Must be set before starting the thread
daemonThread.start();
```
