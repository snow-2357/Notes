# Static, Final, and Access Modifiers

This section covers the keywords that control the visibility, behavior, and mutability of your Java code.

---

## 1. Access Modifiers

Access modifiers define the scope and visibility of a class, variable, method, or constructor.

| Modifier | Class | Package | Subclass | World |
| :--- | :--- | :--- | :--- | :--- |
| **`public`** | Yes | Yes | Yes | Yes |
| **`protected`** | Yes | Yes | Yes | No |
| **`default`** (no keyword) | Yes | Yes | No | No |
| **`private`** | Yes | No | No | No |

---

## 2. The `static` Keyword

The `static` keyword means the member belongs to the **class** itself rather than to a specific instance (object).

- **Static Variables**: Shared among all objects of the class. Only one copy exists in memory.
- **Static Methods**: Can be called without creating an object. They can only access other static members.
- **Static Blocks**: Used to initialize static variables. Runs once when the class is loaded.

```java
public class Counter {
    static int count = 0; // Shared across all instances

    public Counter() {
        count++;
    }

    public static void displayCount() {
        System.out.println("Count: " + count);
    }
}
```

---

## 3. The `final` Keyword

The `final` keyword is used to restrict the user. It can be applied to:

- **Final Variables**: Once assigned, the value cannot be changed (Constants).
- **Final Methods**: Cannot be overridden by subclasses.
- **Final Classes**: Cannot be inherited (e.g., `String` is a final class).

```java
public class Constants {
    public static final double PI = 3.14159; // Constant
}

final class Immutable { } // Cannot be extended
```

---

## 4. Combinations

- **`static final`**: Often used to create constants that are shared by all instances and never change.
  ```java
  public static final String APP_NAME = "MyJavaApp";
  ```
- **`private static`**: Used for internal helper variables that belong to the class.

---

## 5. Practical Example: Utility Class

A utility class often uses `private` constructors to prevent instantiation, and `static` methods for functionality.

```java
public class StringUtils {
    // Private constructor prevents instantiation
    private StringUtils() {}

    public static String reverse(String str) {
        return new StringBuilder(str).reverse().toString();
    }
}

// Usage
String reversed = StringUtils.reverse("Java");
```
