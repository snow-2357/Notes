# Classes, Objects, and Constructors

Java is an Object-Oriented Programming (OOP) language. Everything in Java is associated with classes and objects, along with its attributes and methods.

---

## 1. Classes and Objects

- **Class**: A blueprint or template for creating objects. It defines the properties (attributes) and behaviors (methods) that its objects will have.
- **Object**: An instance of a class. It is a real-world entity that has a state and behavior.

```java
// The Class
public class Car {
    String color;
    String model;

    void drive() {
        System.out.println("The car is driving");
    }
}

// Creating an Object
Car myCar = new Car(); 
myCar.color = "Red";
myCar.drive();
```

---

## 2. Constructors

A **Constructor** is a special method that is used to initialize objects. It is called when an object of a class is created.

### Rules for Constructors:
1.  Constructor name must be the same as the class name.
2.  Constructor must have no explicit return type (not even `void`).
3.  A constructor is called automatically when an object is created using the `new` keyword.

### Types of Constructors:
1.  **Default Constructor**: If you don't define any constructor, Java automatically provides a no-argument constructor that initializes member variables with default values.
2.  **Parameterized Constructor**: A constructor that has parameters to initialize instance variables with specific values.

```java
public class Person {
    String name;
    int age;

    // Parameterized Constructor
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    void display() {
        System.out.println(name + " is " + age + " years old.");
    }
}

// Usage
Person p1 = new Person("Alice", 30);
p1.display();
```

---

## 3. The `this` Keyword

The `this` keyword refers to the current object in a method or constructor. It is most commonly used to eliminate the confusion between class attributes and parameters with the same name.

```java
public class Account {
    int balance;

    public Account(int balance) {
        this.balance = balance; // 'this.balance' is the class attribute, 'balance' is the parameter
    }
}
```

---

## 4. Constructor Overloading

Like methods, constructors can also be overloaded. This allows you to initialize an object in different ways.

```java
public class Rectangle {
    int length;
    int width;

    // Constructor 1: For a square
    public Rectangle(int side) {
        this.length = side;
        this.width = side;
    }

    // Constructor 2: For a rectangle
    public Rectangle(int l, int w) {
        this.length = l;
        this.width = w;
    }
}
```
