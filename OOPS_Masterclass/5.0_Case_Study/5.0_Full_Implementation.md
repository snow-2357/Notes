# 5.0 Case Study: Payment Orchestrator

Let's apply everything we've learned to build a professional-grade Payment System.

## The Goal
A system that can handle multiple payment providers (Stripe, PayPal, Crypto) and process orders.

## Step 1: Define the Base Strategy (Abstraction)
```javascript
class PaymentProvider {
  processPayment(amount) {
    throw new Error("Method must be implemented");
  }
}
```

## Step 2: Specific Implementations (Polymorphism)
```javascript
class StripeProvider extends PaymentProvider {
  processPayment(amount) {
    console.log(`Charging $${amount} via Stripe...`);
    return { status: 'success', id: 'str_123' };
  }
}

class CryptoProvider extends PaymentProvider {
  processPayment(amount) {
    console.log(`Generating QR for ${amount} BTC...`);
    return { status: 'pending', id: 'crypto_456' };
  }
}
```

## Step 3: The Orchestrator (Facade & Dependency Injection)
```javascript
class PaymentOrchestrator {
  constructor(provider) {
    this.provider = provider; // Injected
  }

  async checkout(order) {
    console.log(`Processing Order #${order.id}`);
    const result = await this.provider.processPayment(order.total);
    
    if (result.status === 'success') {
      this.#notifyUser(order);
    }
    return result;
  }

  #notifyUser(order) {
    console.log(`Receipt sent for Order #${order.id}`);
  }
}
```

## Step 4: Putting it together
```javascript
const order = { id: 501, total: 299 };

// Want to pay with Stripe?
const stripeCheckout = new PaymentOrchestrator(new StripeProvider());
stripeCheckout.checkout(order);

// Want to pay with Crypto?
const cryptoCheckout = new PaymentOrchestrator(new CryptoProvider());
cryptoCheckout.checkout(order);
```

## Key OOP Pillars Used:
*   **Abstraction:** The Orchestrator only knows about the `.processPayment()` method.
*   **Polymorphism:** Different providers behave differently but share the same interface.
*   **Encapsulation:** The `#notifyUser` method is private to the Orchestrator.
*   **DI:** We inject the provider into the Orchestrator.
