# 2.3 Static Members: Class-Level Logic

Static properties and methods belong to the **class itself**, not to the instances created from the class.

## Why use Static?
Use `static` for utility functions or data that should be shared across all instances, or logic that doesn't depend on the state of a specific object.

```javascript
class MathUtils {
  static PI = 3.14159;

  static calculateCircleArea(radius) {
    return this.PI * (radius ** 2);
  }
}

console.log(MathUtils.PI); // ✅ Access via class name
console.log(MathUtils.calculateCircleArea(5)); // ✅ Works

const math = new MathUtils();
// console.log(math.PI); // ❌ Undefined (Instances don't have static members)
```

## Common Use Cases
1.  **Utility Methods:** Like `Math.random()` or `Date.now()`.
2.  **Factory Methods:** Creating instances in a specific way.
    ```javascript
    class User {
      constructor(name, role) { this.name = name; this.role = role; }

      static createAdmin(name) {
        return new User(name, 'admin');
      }
    }
    const admin = User.createAdmin("Simanta");
    ```
3.  **Configuration/Constants:** Values that apply to the whole class logic.
