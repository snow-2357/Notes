# 2.2 This and Binding: Managing Context

The `this` keyword refers to the "owner" of the function being executed. In OOP, managing `this` is critical because it's how methods access object properties.

## The Context Problem
When you pass a class method as a callback (e.g., to an event listener or a timer), it loses its connection to the object.

```javascript
class Counter {
  constructor() {
    this.count = 0;
  }

  increment() {
    this.count++;
    console.log(this.count);
  }

  start() {
    // ❌ Error! 'this' will be undefined inside the setInterval callback
    // setInterval(this.increment, 1000); 

    // ✅ Solution 1: Arrow Functions (Inherit 'this' from parent scope)
    setInterval(() => this.increment(), 1000);

    // ✅ Solution 2: .bind()
    // setInterval(this.increment.bind(this), 1000);
  }
}
```

## Common Scenarios
1.  **Implicit Binding:** `obj.method()` -> `this` is `obj`.
2.  **Explicit Binding:** `method.call(obj)`, `method.apply(obj)`, or `method.bind(obj)`.
3.  **New Binding:** `new MyClass()` -> `this` is the new instance.
4.  **Arrow Functions:** They **do not** have their own `this`. They capture it from the surrounding code.

## Pro Tip: Hard Binding in Constructors
For performance in high-frequency callbacks, bind methods in the constructor:
```javascript
constructor() {
  this.increment = this.increment.bind(this);
}
```
