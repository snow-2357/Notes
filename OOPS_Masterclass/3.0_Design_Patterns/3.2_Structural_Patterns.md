# 3.2 Structural Patterns: Composition & Relationships

Structural patterns explain how to assemble objects and classes into larger structures while keeping these structures flexible and efficient.

## 1. Adapter Pattern
Allows objects with incompatible interfaces to collaborate.
**Common Use Case:** Wrapping a 3rd party library so you can swap it later without changing your app code.

```javascript
// Old interface (e.g., legacy code)
class OldCalculator {
  operations(v1, v2, op) {
    if (op === 'add') return v1 + v2;
  }
}

// New interface we want to use
class NewCalculator {
  add(v1, v2) { return v1 + v2; }
}

// Adapter
class CalcAdapter {
  constructor() { this.calc = new NewCalculator(); }
  operations(v1, v2, op) {
    if (op === 'add') return this.calc.add(v1, v2);
  }
}
```

## 2. Facade Pattern
Provides a simplified interface to a library, a framework, or any other complex set of classes.
**Common Use Case:** A complex API wrapper.

```javascript
class CPU { freeze() {} jump() {} execute() {} }
class Memory { load() {} }
class HardDrive { read() {} }

class ComputerFacade {
  constructor() {
    this.cpu = new CPU();
    this.mem = new Memory();
    this.hd = new HardDrive();
  }

  start() {
    this.cpu.freeze();
    this.mem.load(0, this.hd.read(0, 1024));
    this.cpu.jump(0);
    this.cpu.execute();
  }
}

const pc = new ComputerFacade();
pc.start(); // Simple call hides complex internal logic
```

## 3. Decorator Pattern
Lets you attach new behaviors to objects by placing these objects inside special wrapper objects that contain the behaviors.
**Common Use Case:** Adding logging or validation to a method dynamically.

```javascript
function loggerDecorator(instance) {
  const originalMethod = instance.save;
  instance.save = function(data) {
    console.log("LOG: Saving data...", data);
    return originalMethod.apply(this, [data]);
  };
  return instance;
}

class UserRepo {
  save(data) { console.log("Data saved to DB"); }
}

const repo = loggerDecorator(new UserRepo());
repo.save({ name: 'Simanta' });
```
