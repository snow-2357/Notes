# 3.3 Behavioral Patterns: Communication

Behavioral patterns are concerned with algorithms and the assignment of responsibilities between objects.

## 1. Strategy Pattern
Defines a family of algorithms, encapsulates each one, and makes them interchangeable.
**Common Use Case:** Payment gateways (Stripe vs PayPal).

```javascript
class PaymentProcessor {
  constructor(strategy) { this.strategy = strategy; }
  process(amount) { return this.strategy.pay(amount); }
}

class Stripe { pay(amount) { console.log(`Paid ${amount} via Stripe`); } }
class PayPal { pay(amount) { console.log(`Paid ${amount} via PayPal`); } }

const checkout = new PaymentProcessor(new Stripe());
checkout.process(100);
```

## 2. Observer Pattern (Pub/Sub)
Defines a subscription mechanism to notify multiple objects about any events that happen to the object they’re observing.
**Common Use Case:** Event listeners, Chat apps.

```javascript
class NewsAgency {
  constructor() { this.subscribers = []; }
  subscribe(sub) { this.subscribers.push(sub); }
  notify(news) {
    this.subscribers.forEach(sub => sub.update(news));
  }
}

class User {
  constructor(name) { this.name = name; }
  update(news) { console.log(`${this.name} received: ${news}`); }
}

const bbc = new NewsAgency();
bbc.subscribe(new User("Alice"));
bbc.notify("Breaking News!");
```

## 3. State Pattern
Lets an object alter its behavior when its internal state changes.
**Common Use Case:** Order status (Pending -> Shipped -> Delivered).

```javascript
class Order {
  constructor() { this.state = new PendingState(this); }
  setState(state) { this.state = state; }
  next() { this.state.next(); }
}

class PendingState {
  constructor(order) { this.order = order; }
  next() { 
    console.log("Order is now Shipped.");
    this.order.setState(new ShippedState(this.order)); 
  }
}

class ShippedState {
  constructor(order) { this.order = order; }
  next() { console.log("Order is Delivered."); }
}
```
