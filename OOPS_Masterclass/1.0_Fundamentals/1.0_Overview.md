# 1.0 OOPS Overview: Procedural vs. OOP

Object-Oriented Programming (OOP) is a paradigm that organizes software design around **data**, or objects, rather than functions and logic.

## Procedural Programming (The "Recipe" approach)
In procedural programming, you write a list of instructions for the computer to follow. You have global variables and functions that modify them.

```javascript
let balance = 100;

function deposit(amount) {
  balance += amount;
}

function withdraw(amount) {
  if (balance >= amount) {
    balance -= amount;
  }
}

// Problem: Any function can accidentally modify 'balance' from anywhere.
```

## Object-Oriented Programming (The "Component" approach)
In OOP, you group related data (properties) and behavior (methods) into a single unit called a **Class**.

```javascript
class Account {
  constructor(initialBalance) {
    this.balance = initialBalance;
  }

  deposit(amount) {
    this.balance += amount;
  }

  withdraw(amount) {
    if (this.balance >= amount) {
      this.balance -= amount;
    }
  }
}

const myAccount = new Account(100);
// Logic and data are now bundled together.
```

## Why use OOP?
1.  **Modularity:** Easier to troubleshoot and maintain.
2.  **Reusability:** Code can be reused through inheritance.
3.  **Scalability:** Better for large, complex systems where multiple developers work together.
4.  **Security:** Data can be hidden (Encapsulation) from unauthorized access.
