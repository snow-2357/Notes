# 1.3 Inheritance: Code Reusability

Inheritance allows a class (child) to derive properties and methods from another class (parent). This helps in avoiding code duplication.

## The "Is-A" Relationship
Inheritance should be used when a child class "is a" type of parent class (e.g., a Dog *is an* Animal).

```javascript
// Parent Class
class HTMLComponent {
  constructor(id) {
    this.id = id;
  }

  focus() {
    console.log(`Element ${this.id} is now focused.`);
  }

  render() {
    // Base render logic
  }
}

// Child Class
class Button extends HTMLComponent {
  constructor(id, label) {
    super(id); // Calls the parent constructor
    this.label = label;
  }

  // Adding specific behavior
  click() {
    console.log(`Button [${this.label}] was clicked.`);
  }
}

const submitBtn = new Button("btn-01", "Submit");
submitBtn.focus(); // ✅ Inherited from HTMLComponent
submitBtn.click(); // ✅ Specific to Button
```

## The `super` Keyword
1.  `super(args)`: Calls the parent's constructor. **Must be called first** in the child constructor.
2.  `super.method()`: Calls a method from the parent class.

## When to Avoid Inheritance
Don't use inheritance just to share code. Use **Composition** if the relationship is "Has-A" (e.g., a Car *has an* Engine, it's not a type of Engine).
