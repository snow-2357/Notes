# 1.4 Polymorphism: Many Shapes

Polymorphism allows objects of different classes to be treated as instances of a common parent class. The word means "many shapes."

## The Concept: Method Overriding
Even if multiple classes inherit from the same parent, they can provide their own specific implementation of a method.

```javascript
class Shape {
  draw() {
    console.log("Drawing a generic shape...");
  }
}

class Circle extends Shape {
  draw() {
    console.log("Drawing a Circle ◯");
  }
}

class Square extends Shape {
  draw() {
    console.log("Drawing a Square □");
  }
}

// Polymorphism in action:
const shapes = [new Circle(), new Square(), new Shape()];

shapes.forEach(shape => {
  shape.draw(); // Each object "knows" how to draw itself
});
```

## Polymorphism via "Duck Typing"
In JavaScript (being dynamically typed), we often use "Duck Typing": *If it walks like a duck and quacks like a duck, it's a duck.* We don't always need a formal parent class; we just need the objects to have the same method name.

```javascript
class PDFExporter {
  export(data) { console.log("Exporting PDF..."); }
}

class CSVExporter {
  export(data) { console.log("Exporting CSV..."); }
}

function saveFile(exporter, data) {
  exporter.export(data); // Works with any object that has an .export() method
}

saveFile(new PDFExporter(), {}); 
saveFile(new CSVExporter(), {});
```

## Why use Polymorphism?
1.  **Extensibility:** You can add new classes (e.g., `Triangle`) without changing the code that uses the `Shape` objects.
2.  **Cleaner Code:** Removes the need for complex `if/else` or `switch` statements to check object types.
